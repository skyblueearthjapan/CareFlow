スケジュール変更／新規患者様編

CareFlow 訪問看護スケジューリング ／ 「新しい患者さんを受け入れて予定に入れる」ための手引き

🌐 https://carelink.kaipoke-api.net 👤 登録できるのは 管理者・マネージャー 📕 別冊：既存患者様編
新規患者さんの受け入れも、「空きを確認 → 受けられるか判断 → 予定に入れる」という実務の流れは 既存患者様編とまったく同じです。違うのは 「カルテ（患者マスタ）を新しく作る」 一手間だけ。 本書はその「新規ならではの部分」に絞って説明します。空き枠の確認方法や予定変更の細かな操作は、別冊 「スケジュール変更／既存患者様編」を参照してください。

1 このマニュアルについて

新規患者さんを受け入れるときの流れを、変更を 「誰が行うか」 で2パターンに分けて説明します（既存編と同じ分け方）。

パターンこんなとき章
A：事務所で受付 → PCで登録
管理者マネージャー		 電話などで依頼を受け、その場でPCで登録・予定化する第4章
B：現場で情報収集 → 持ち帰り → 管理者登録
スタッフ → 管理者		 現場で必要情報をヒアリングし、事務所に持ち帰って管理者が登録する第5章
大前提（権限）：新規患者の登録ができるのは 管理者・マネージャーです。 現場スタッフ（staff）は新規登録できません（画面に登録ボタンが出ません）。だから現場は「情報を集めて持ち帰り、管理者が登録」という形になります（第5章）。

2 既存との違いは「1点」だけ

2.1 違い＝最初に「カルテ作成」が要る

既存患者さんは、すでにカルテ（患者マスタ）と「毎週の型」があるので、予定を動かすだけでした。 新規患者さんは その土台がまだ無いので、いちばん最初に カルテを作る 必要があります。あとは既存と同じです。

2.2 全体の流れ（新規も既存も同じ）

  1. 空きを確認する… いつ・どのコースなら受け入れられるかを確認（方法は既存編 第3章と同じ：曜日テーブルの空き時間／受け入れ枠○△×／現場ボード）。
  2. 受けられるか判断する… 空き・スタッフ・移動などから管理者が可否を判断。
  3. カルテを作る（新規だけ）… 患者情報を登録。
  4. 予定に入れる… 提案→採用、または型を作って「週を生成」、最後にスタッフ割付。
空き枠の見方（PC曜日テーブルの「空き時間」、受け入れ枠の○△×、スマホ現場ボード）は 別冊「既存患者様編」第3章と共通です。本書では繰り返しません。

3 新規カルテに必要な情報

登録フォームの項目です。必ず要るのは「氏名」だけですが、スケジュールを組むには 住所 が実質必要です（住所から自動で地図上の位置と担当拠点が決まります）。

3.1 必須・推奨・任意の一覧

住所を入れるとどうなる？
住所を入力すると、数百ミリ秒後に 自動で地図上の座標が入り、担当拠点（稲毛／都賀など）も自動判定されます。 うまく見つからないときは「住所が見つかりませんでした」と出るので、その場合は座標を手入力するか拠点を手動選択します。

4 パターンA：事務所で受付 → PCで登録

対象者 管理者マネージャー

電話などで依頼を受けたら、その場でPCで登録します。3つの方法があり、A-1がいちばん早いです。

A-1 「新規提案」で登録＋予定化を一気通貫（最短・おすすめ）

スケジュール画面の 「新規提案」 ボタンから、空き枠の提案 → 採用 → 患者登録 → 型の確定 までを 一度に行えます（承認不要）。

  1. スケジュール画面で対象の週を開き、ツールバーの 「新規提案」 を押します。
  2. モーダル上部のタブで 「新規の方」 を選びます。
  3. 氏名・住所と 希望（週回数・希望曜日・サービス時間・時間帯・性別制限・2名体制）を入力します。
  4. 「提案する」 を押すと、入れられる空き枠が曜日ごとに提案されます（この時点では保存されません）。
  5. 採用する枠を選び、「登録へ進む」 → 内容を確認して 確定。患者の登録と固定枠の確定が同時に完了します。
  6. 必要に応じて 「自動スタッフ割付」 で担当を付けます。

A-2 じっくり登録する（新規登録フォーム）

提案を使わず、先にカルテだけ作って、あとで予定を組みたいときの方法です。

  1. 左メニューの「患者」→ 「新規登録」（/patients/new「患者 新規登録」）を開きます。
  2. 第3章の項目を入力します（氏名・住所は必ず。住所で座標・拠点が自動設定）。
  3. 「登録」 を押すと患者が作成され、患者詳細ページへ移動します。
  4. 患者詳細で 固定訪問パターン を作成します（「希望から自動生成」で希望から曜日・時刻を一括入力できます）。
  5. スケジュール画面で 「週を生成」。型に沿って予定が作られます。型のない患者は 保留プール に入るので、「プール投入」 から空き枠へ配置します。
  6. 「自動スタッフ割付」 で担当を付けて完了です。
型を作っただけでは予定に入りません。「週を生成」または「プール投入」で実際の予定に反映します（既存編 第2章の大事なルールと同じ）。

A-3 Excelカルテで登録する

まとめて登録する場合や、紙で集めた情報をまとめて入れる場合は、Excelカルテが使えます。

  1. 患者画面から 「カルテテンプレート」 をダウンロード（ヒアリング記入用の空カルテ）。
  2. 新規患者の情報を記入（1患者1カルテ）。
  3. カルテを取り込み（インポート）。新規の行は「新規追加」として登録されます。まず プレビュー で確認してから反映できます。
  4. 登録後、固定訪問パターンを整え、スケジュール画面で 「週を生成」。
Excelカルテの操作は PC（管理者・マネージャー）のみです。スマホ（現場）にはExcelカルテの画面はありません。

5 パターンB：現場で情報収集 → 持ち帰り → 管理者が登録

対象者 現場スタッフ → マネージャー管理者

現場で新規の相談を受けたときの流れです。現場スタッフは新規登録できないため、必要情報を集めて持ち帰り、管理者が登録します。

B 全体の流れ

1
現場スタッフ
現場で必要情報をヒアリング

ヒアリングシートの項目（氏名・住所・保険・希望曜日/時間・2名体制の要否など）を確認します。スマホの 受け入れ枠（○△×） を一緒に見て、入れられそうな曜日・時間帯も当たりを付けられます。

2
現場スタッフ
情報を持ち帰る

記入したヒアリングシート（または印刷カルテ・メモ）を事務所へ。電話受付の場合は、その場で管理者がPC入力できるので持ち帰り不要です。

3
マネージャー管理者
管理者が空きを確認し、受け入れを判断

PCで空き枠（曜日テーブル／受け入れ枠）を確認し、スタッフ稼働や移動も踏まえて可否を判断します。

4
マネージャー管理者
管理者がPCで登録＋予定化（＝パターンA）

持ち帰った情報で 「新規提案」（最短）か 新規登録フォームで登録し、予定に入れます。

5
マネージャー管理者 → 現場スタッフ
結果を現場・患者へ連絡

受け入れ可否と初回訪問日を共有します。担当に決まったスタッフは、スマホの「今日／今週」で新しい予定を確認できます。

現場での情報収集の手段と、できる／できないこと

情報収集の手段

  • ヒアリングシート／印刷カルテ … PCで「カルテテンプレート」を印刷して持参し、現場で記入。
  • メモ … 第3章の必要項目を控える。
  • 受け入れ枠（スマホ） … ○の曜日・時間帯を患者さんと一緒に確認。
  • （マネージャー・管理者の場合）モバイルで直接登録 … 現場ボードの「患者管理」から新規登録も可能（その場で即時登録）。

7 よくある質問・注意

状況・質問答え・対処
最低限、何を入れれば登録できる？氏名だけでも登録は可能。ただし予定を組むには 住所 がほぼ必須（座標・拠点が自動設定されます）。
患者コードは決めないとダメ？いいえ。空欄で自動採番されます。決まり番号があれば入力（重複はエラー）。
住所を入れたのに座標が付かない「住所が見つかりませんでした」と出たら、住所表記を見直すか、座標を手入力／拠点を手動選択。
登録したのに予定に出てこないカルテ登録＝予定化ではありません。固定訪問パターン→「週を生成」、または 「プール投入」で予定に入れます（「新規提案」なら同時に完了）。
現場スタッフが新規の相談を受けたスタッフは登録できません。ヒアリングシートで情報を集めて持ち帰り、管理者が登録します。
2名体制の患者の枠提案がおかしい提案は1名前提で算出されます。採用後に相方の枠を別途確認してください。
