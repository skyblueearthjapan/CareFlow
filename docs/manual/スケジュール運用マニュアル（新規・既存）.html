0 はじめに・ログイン 共通

新規・既存どちらの場合も、まずはログインから。スケジュールを 変更・登録できるのは管理者・マネージャー、スタッフは閲覧のみです。

  1. ブラウザで https://carelink.kaipoke-api.net を開きます（PCはダッシュボード、スマホはホームが開きます）。
  2. メールアドレスとパスワードを入れて 「ログイン」（管理者・マネージャーはメールアドレスでログイン）。
  3. 初回は仮パスワードで入ると変更画面が出ます。新しいパスワード（8文字以上・英字と数字を両方）を設定します。
アカウントの発行（新しいスタッフのログイン作成・仮パスワード配布）や受け入れ枠の詳しい見方は、別冊 「CareFlow 利用マニュアル」を参照してください。本書はスケジュール運用に絞っています。
共有のスマホ・タブレットを使ったら、使用後は必ず ログアウト（スマホはマイページ下部）してください。

3 判断する：受けられるか決める 共通

空きが見つかったら、管理者・マネージャーが受け入れ可否を判断します。見るポイントは新規・既存で同じです。

  • 空き枠があるか（人数の空き・時間の空き）。
  • スタッフの稼働（その曜日・時間に動ける担当がいるか、性別制限・2名体制を満たせるか）。
  • 移動のしやすさ（前後の訪問とご住所が近いか）。
  • 受け入れ枠の○△×はあくまで目安。最終判断は人が行います。
既存の変更では「今回だけ動かすのか、今後ずっと変えるのか」も判断に含めます（次章で操作が分かれます）。
新規では「初回いつから始めるか」「希望どおりの曜日・時間で枠が取れるか」を判断し、足りなければ別の曜日・コースを候補にします。

4 情報を入力する 新規 既存

新規はここが本番。カルテ（患者マスタ）を新しく作ります。必ず要るのは「氏名」だけですが、予定を組むには 住所 が実質必要です（住所から地図上の位置と担当拠点が自動で決まります）。

項目区分ポイント
氏名必須唯一の必須項目。
住所実質必須入力すると座標と担当拠点が自動設定。距離計算に使います。
患者コード任意空欄でOK（自動採番）。決まり番号があれば入力。
保険区分推奨医療／介護。
性別制限 / 2名体制推奨「女性のみ」「常に2名」などは割り当ての条件に。
希望訪問パターン推奨週何回・希望曜日・サービス時間・時間帯。提案や型の元に。
備考任意アレルギー・注意・申し送り。
住所を入れると：自動で地図上の座標が入り、担当拠点（稲毛／都賀など）も自動判定。見つからないときは座標手入力／拠点を手動選択します。

5 予定に反映する 新規 既存

操作できるのは 管理者マネージャー（PC・スケジュール画面）

A-1 スケジュール画面から患者登録（おすすめ）

スケジュール画面のツールバー 「＋新規患者登録」 から、患者マスタと同等の登録フォームを その場で開けます（別タブ不要・承認不要）。希望訪問パターン（週回数・希望曜日・サービス時間など）も同じフォームで入力でき、登録後すぐに保留プールへ反映されます。

  1. 対象の週を開き、ツールバーの 「＋新規患者登録」 を押す。
  2. 登録ダイアログで 氏名・住所・希望訪問パターン（週回数・希望曜日・サービス時間・時間帯・性別制限・2名体制）を入力し 「登録」。
  3. 登録成功後、保留プール に自動表示される（希望回数 ≥ 1 が条件）。
  4. 保留プールから 個別提案（プール候補リスト）または 一括投入 で空き枠へ配置。
  5. 必要に応じて 「自動スタッフ割付」 で担当を付ける。

A-2 患者マスタから登録（じっくり登録）

  1. 「患者」→ 「新規登録」（/patients/new）で氏名・住所・希望訪問パターンなどを入力し 「登録」。
  2. スケジュール画面で 「週を生成」。希望パターンが登録済みの患者は 保留プール に入るので 個別提案 または 一括投入 で空き枠へ配置。
  3. 「自動スタッフ割付」 で担当を付けて完了。
登録しただけでは予定に入りません。「＋新規患者登録」または患者マスタで登録し、希望訪問パターンを設定 → 保留プールに表示 → 個別提案／一括投入で予定化します。

A-3 Excelカルテで登録

  1. 患者画面から 「カルテテンプレート」 をDL（ヒアリング記入用）。
  2. 記入して 取り込み（インポート）。新規行は「新規追加」。まずプレビューで確認。
  3. 登録後、固定訪問パターンを整え 「週を生成」。
ExcelカルテはPC（管理者・マネージャー）のみ。スマホにはExcelカルテ画面はありません。

よくある質問

質問答え
登録・変更したのに予定が変わらない型を変えたら 「週を生成」 が必要。新規患者は登録後に保留プールから 個別提案／一括投入 で予定化します。
動かしたい時間に空きがないそのコースが満員。別コース・別の空き時間を2章で探すか管理者が調整。
現場スタッフが相談を受けたスタッフは変更・登録不可。シート/メモで持ち帰り、管理者が反映（6章）。
新規で最低限なにを入れる？氏名だけでも登録可。予定化には 住所 がほぼ必須（座標・拠点が自動設定）。
患者コードは決める？空欄で 自動採番。決まり番号があれば入力（重複はエラー）。
今週だけのつもりが毎週変わった編集で「患者マスターを更新（永続）」を選ぶと今後ずっとに。今回だけは ドラッグか「今週限定で変更」。
「週を生成」で手動変更は消える？自動分のみ作り直し、手動変更・完了/中止は残ります。
画面が古い気がするスマホは開き直し、PCは Ctrl+Shift+R。
