CareFlow 現場スタッフ クイックガイド

訪問看護スケジューリング ／ 1枚目：基本の使い方
ログイン先
carelink.kaipoke-api.net

1ログインする

  1. スマホのブラウザで carelink.kaipoke-api.net を開く
  2. スタッフID（例：S002）とパスワード yoriyori0401 を入れて ログイン
パスワードは全員共通（yoriyori0401）です。初回のパスワード変更などの作業はありません。
パスワードは変更しないでください。変更すると共通パスワードで入れなくなります。もし「パスワードの変更が必要です」という画面が出たら、変更せず管理者へ連絡してください。

入れないとき → スタッフID（大文字 S+数字）／パスワードのつづりを確認。だめなら管理者に再確認を依頼。

2ホーム画面に追加（おすすめ）

毎回アドレスを打たずアプリのように開けます。

iPhone（Safari）
共有ボタン → 「ホーム画面に追加」 → 追加

Android（Chrome）
⋮メニュー → 「アプリをインストール」/「ホーム画面に追加」

3毎日の使い方（下のメニューで切替）

🏠ホーム
📅今日
📊今週
👤マイページ
  • ホーム … あいさつと、今日・今週・今月の訪問件数。
  • 今日 … 本日の訪問が時間順に。状態＝未訪問／訪問中／完了。タップで詳細。
  • 今週 … 月〜日の予定を曜日ごとに確認。
  • マイページ … プロフィール、シフト希望提出、表示設定、ログアウト。
表示されるのは 自分の担当の訪問。出ないときはアカウントとスタッフ情報の紐付けを管理者に確認。

4受け入れ枠の見方（「いつ空いてる？」と聞かれたら）

曜日 × 時間帯で、受け入れられるかのおおよその目安を記号で表示。スマホの受け入れ枠画面で確認できます（縦＝時間帯／横＝曜日）。

相談を受けたら一緒に画面を見て「○の曜日・時間帯」を候補に。最終判断は管理者。

予定を変えたいと言われたら（既存の患者さん）

ログイン先
carelink.kaipoke-api.net

5すでに通っている患者さんの予定変更

現場スタッフは予定を自分で変更できません（閲覧専用）。聞いた内容を事務所に持ち帰り、管理者が変更します。

あわてて約束せず、下のメモを取って持ち帰りましょう。受け入れ枠（手順4）で「○の時間帯」を一緒に確認しておくと、管理者の判断が早くなります。

📋 変更メモ（既存の患者さん）

患者さんの名前
今の予定（曜日・時間）
希望（曜日・時間）
今回だけ / 今後ずっと
理由・備考

→ メモを 管理者・マネージャー に渡す → 管理者が空きを確認して変更 → 結果が「今日／今週」に反映されます。

★覚えておく区別

  • 今回だけ … 今週のその日だけ動かす（例：今週水曜だけ午後に）。
  • 今後ずっと … 毎週の曜日・時間を恒久的に変える。

どちらの希望かを聞いておくと、管理者の対応が早くなります。

♥現場の役割

  • 現場は 確認とヒアリング が役割。
  • 変更・登録は管理者・マネージャーが担当。
  • 受け入れ枠は目安。確約はしない。

6新規（はじめての）患者さんの相談を受けたら

新規患者の登録も、現場スタッフはできません。必要な情報を聞き取って持ち帰り、管理者が登録します。

やることは 「必要情報のヒアリング」 です。下のシートの項目を埋めて持ち帰りましょう。受け入れ枠（手順4）で「○の曜日・時間帯」も一緒に確認しておくと安心です。

📋 新規患者ヒアリングシート

お名前（カナ）必須
ご住所ほぼ必須
保険区分（医療/介護）
性別 / 性別制限
2名体制が必要か
希望（週何回・曜日・時間）
サービス時間（分）/ 開始希望日
備考・注意事項

→ シートを 管理者・マネージャー に渡す → 管理者がPCで登録し予定に入れる → 担当に決まれば「今日／今週」に反映。

ご住所はできるだけ正確に。住所から地図上の位置と担当拠点が自動で決まり、予定づくりに使われます。

7困ったとき

  • ログインできない → スタッフコード（S+数字）と共通パスワード（1枚目の手順1）を確認。だめなら管理者に再確認依頼。
  • 「パスワードの変更が必要です」と出た → 変更せず、管理者へ連絡。
  • 「オフラインです」 → 電波・Wi-Fiを確認して開き直す。
  • 予定が古い気がする → 画面を下に引いて更新／アプリを開き直す。
  • 自分の訪問が出ない → アカウントとスタッフ情報の紐付けがまだです。管理者に確認して、紐付けしてもらうか、一度ログアウト→再ログインしてください。

8安全に使うために

  • 共有端末は使い終わったら必ずログアウト。
  • パスワードは社外の人に教えない・自分で変更しない。
  • 患者情報は業務以外で見ない・共有しない。
新規も既存も同じ：現場は確認とヒアリング、登録・変更は管理者。

★これだけ覚えればOK

  • 開く … carelink.kaipoke-api.net（ホーム画面に追加が便利）
  • 入る … スタッフID＋共通パスワード（変更しない）
  • 確認 … 「今日」「今週」で自分の訪問
  • 到着・退出 … 訪問を開いてQRで記録（4枚目）
  • 空き … 受け入れ枠 ○＝可 △＝相談 ×＝なし
  • 既存の変更相談 … 変えずにメモして管理者へ
  • 新規の相談 … ヒアリングシートを埋めて管理者へ
  • 終了 … 共有端末は必ずログアウト

QRチェックイン（到着・退出の記録）

訪問看護スケジューリング ／ 4枚目：訪問先でのQR読み込みとGPSの準備
ログイン先
carelink.kaipoke-api.net

9準備：Chrome で位置情報（GPS）を使えるようにする

QRチェックインでは、正しい場所で記録されたかを確認するために位置情報を使います。初回利用の前に、お使いのスマホで Chrome アプリの位置情報を有効化してください（1回設定すればOK）。

iPhone（Chrome アプリ）

  1. ホームの 「設定」 を開く
  2. プライバシーとセキュリティ → 位置情報サービス を オン
  3. 下のアプリ一覧から Chrome を選ぶ
  4. 「このアプリの使用中」 を選び、「正確な位置情報」もオン
  5. Chrome で CareFlow を開き、「位置情報の使用を許可しますか？」と出たら 「許可」

Android（Chrome アプリ）

  1. 「設定」 → アプリ → Chrome を開く
  2. 権限 → 位置情報 をタップ
  3. 「アプリの使用中のみ許可」 を選び、「正確な位置情報を使用」もオン
  4. Chrome で CareFlow を開き、「位置情報の使用を許可しますか？」と出たら 「許可」

※機種により文言が少し異なります（例：権限→「位置情報」が「許可」の中にある等）。

アプリ内で「位置情報の利用が許可されていません」と表示されたら、この設定を見直してから画面の 「位置を再取得」 を押してください。あわせて カメラの許可（QR読み取りに必要）も、聞かれたら「許可」を選んでください。

10到着したら（入室時のQR読み込み）

  1. 下メニュー 「今日」 → 該当の訪問をタップ
  2. 「QRで到着を記録」 をタップ（カメラが起動）
  3. 患者様宅に掲示された QRコードを枠内に合わせる
  4. 「到着の確認」画面で位置の判定を確認し、「到着を記録する」 をタップ
  5. 「到着を記録しました」と出て、状態が 訪問中 に変わる
位置が「登録住所と一致」なら緑表示。大きく離れている場合（目安300m超）は理由の入力が必須になり、「理由を付けて到着を記録」で記録します。

GPSが取れないとき（「測位不良」）もそのまま記録できます。「位置を再取得」で測り直しも可能。

11帰るとき（退出時のQR読み込み）

  1. 訪問中の画面で 「QRで退出を記録」 をタップ
  2. 同じQRコードを枠内に合わせる（到着と共通です）
  3. 位置を確認して記録 → 「訪問を完了しました」と出て、状態が 完了 に変わる
訪問中は サービスメモ（端末内の下書き）と 「写真を撮影 / 選択」 が使えます。写真は退出前にアップロードしてください（完了後は追加できません）。

12QRチェックインで困ったとき

  • カメラが起動しない → カメラ許可を確認。急ぐときは 「QRなしで記録」 でも記録できます（位置情報は記録されます）。
  • 「このQRは無効です」 → 管理者にQRの再発行を依頼。
  • 「このQRは別の患者のものです」 → 読み取ったQRが正しい患者様宅のものか確認。
  • 「このQRは更新されています」 → 古いQRが貼られたままです。管理者へ連絡し、新しいQRに貼り替え。
  • 「測位がタイムアウトしました」 → 屋外や窓際で 「位置を再取得」。
  • 電波がない・送信に失敗 → 「未送信として保存しました」と出れば、電波が戻り次第自動で再送されます。そのまま次へ移動してOK。
QRコードは患者様ごとに1枚（玄関などに掲示・到着/退出共通）。印刷・再発行は管理者が患者詳細ページから行います。
