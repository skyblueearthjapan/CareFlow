ログイン先
carelink.kaipoke-api.net

1ログインする

  1. スマホのブラウザで carelink.kaipoke-api.net を開く
  2. スタッフID（例：S002）とパスワード yoriyori0401 を入れて ログイン
パスワードは全員共通（yoriyori0401）です。初回のパスワード変更などの作業はありません。
パスワードは変更しないでください。変更すると共通パスワードで入れなくなります。もし「パスワードの変更が必要です」という画面が出たら、変更せず管理者へ連絡してください。

入れないとき → スタッフID（大文字 S+数字）／パスワードのつづりを確認。だめなら管理者に再確認を依頼。

2ホーム画面に追加（おすすめ）

毎回アドレスを打たずアプリのように開けます。

iPhone（Safari）
共有ボタン → 「ホーム画面に追加」 → 追加

Android（Chrome）
⋮メニュー → 「アプリをインストール」/「ホーム画面に追加」

3毎日の使い方（下のメニューで切替）

🏠ホーム
📅今日
📊今週
👤マイページ
  • ホーム … あいさつと、今日・今週・今月の訪問件数。
  • 今日 … 本日の訪問が時間順に。状態＝未訪問／訪問中／完了。タップで詳細。
  • 今週 … 月〜日の予定を曜日ごとに確認。
  • マイページ … プロフィール、シフト希望提出、表示設定、ログアウト。
表示されるのは 自分の担当の訪問。出ないときはアカウントとスタッフ情報の紐付けを管理者に確認。

4受け入れ枠の見方（「いつ空いてる？」と聞かれたら）

曜日 × 時間帯で、受け入れられるかのおおよその目安を記号で表示。スマホの受け入れ枠画面で確認できます（縦＝時間帯／横＝曜日）。

○ 受け入れ可能 △ 相談ください × 枠なし 「休」= 定休日

相談を受けたら一緒に画面を見て「○の曜日・時間帯」を候補に。最終判断は管理者。

開き方：現場ボード上部の「受け入れ枠」から（閲覧専用）。開けない端末では管理者に確認を。

予定を変えたいと言われたら（既存の患者さん）

ログイン先

5すでに通っている患者さんの予定変更

現場スタッフは予定を自分で変更できません（閲覧専用）。聞いた内容を事務所に持ち帰り、管理者が変更します。

あわてて約束せず、下のメモを取って持ち帰りましょう。受け入れ枠（手順4）で「○の時間帯」を一緒に確認しておくと、管理者の判断が早くなります。

📋 変更メモ（既存の患者さん）

患者さんの名前
今の予定（曜日・時間）
希望（曜日・時間）
今回だけ / 今後ずっと
理由・備考

→ メモを 管理者・マネージャー に渡す → 管理者が空きを確認して変更 → 結果が「今日／今週」に反映されます。

★覚えておく区別

  • 今回だけ … 今週のその日だけ動かす（例：今週水曜だけ午後に）。
  • 今後ずっと … 毎週の曜日・時間を恒久的に変える。

どちらの希望かを聞いておくと、管理者の対応が早くなります。

♥現場の役割

  • 現場は 確認とヒアリング が役割。
  • 変更・登録は管理者・マネージャーが担当。
  • 受け入れ枠は目安。確約はしない。

6新規（はじめての）患者さんの相談を受けたら

新規患者の登録も、現場スタッフはできません。必要な情報を聞き取って持ち帰り、管理者が登録します。

やることは 「必要情報のヒアリング」 です。下のシートの項目を埋めて持ち帰りましょう。受け入れ枠（手順4）で「○の曜日・時間帯」も一緒に確認しておくと安心です。

ご住所ほぼ必須
保険区分（医療/介護）
性別 / 性別制限
2名体制が必要か
希望（週何回・曜日・時間）
サービス時間（分）/ 開始希望日
備考・注意事項

→ シートを 管理者・マネージャー に渡す → 管理者がPCで登録し予定に入れる → 担当に決まれば「今日／今週」に反映。

ご住所はできるだけ正確に。住所から地図上の位置と担当拠点が自動で決まり、予定づくりに使われます。

7困ったとき

  • ログインできない → スタッフコード（S+数字）と共通パスワード（1枚目の手順1）を確認。だめなら管理者に再確認依頼。
  • 「パスワードの変更が必要です」と出た → 変更せず、管理者へ連絡。
  • 「オフラインです」 → 電波・Wi-Fiを確認して開き直す。
  • 予定が古い気がする → 画面を下に引いて更新／アプリを開き直す。
  • 自分の訪問が出ない → アカウントとスタッフ情報の紐付けがまだです。管理者に確認して、紐付けしてもらうか、一度ログアウト→再ログインしてください。

8安全に使うために

  • 共有端末は使い終わったら必ずログアウト。
  • パスワードは社外の人に教えない・自分で変更しない。
  • 患者情報は業務以外で見ない・共有しない。
新規も既存も同じ：現場は確認とヒアリング、登録・変更は管理者。

★これだけ覚えればOK

  • 開く … carelink.kaipoke-api.net（ホーム画面に追加が便利）
  • 入る … スタッフID＋共通パスワード（変更しない）
  • 確認 … 「今日」「今週」で自分の訪問
  • 空き … 受け入れ枠 ○＝可 △＝相談 ×＝なし
  • 既存の変更相談 … 変えずにメモして管理者へ
  • 新規の相談 … ヒアリングシートを埋めて管理者へ
  • 終了 … 共有端末は必ずログアウト
