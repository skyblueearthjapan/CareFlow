管理者の方へ（最優先のお願い）

第1部 はじめに

1.1 CareFlowとは

CareFlow（ケアフロー）は、訪問看護のスケジュール（訪問予定）を作成・管理するための Webアプリケーションです。事業所（拠点）ごとの訪問計画、スタッフの割り当て、空き枠の確認などを パソコンとスマートフォンの両方から行えます。

  • 事務所のパソコン … スケジュール編成・マスタ管理・受け入れ枠の調整など
  • 現場のスマートフォン … 自分の訪問予定の確認、現場ボードでの当日運用など

1.2 動作環境・推奨ブラウザ

端末推奨ブラウザ備考
パソコン（Windows / Mac）Google Chrome / Microsoft Edge 最新版画面が広いほど操作しやすくなります
iPhone / iPadSafari 最新版ホーム画面に追加してアプリのように使えます
Android スマホGoogle Chrome 最新版同上
インターネット接続が必要です。電波の届かない場所では「オフラインです。ネットワーク接続を確認してください。」と 表示されます。電波の良い場所で再度開いてください。

1.3 PC版とスマホ版の違い

CareFlowは、同じアドレス（https://carelink.kaipoke-api.net）にアクセスしても、 使っている端末を自動で判別して画面が切り替わります。

アクセスした端末最初に開く画面主な用途
パソコンダッシュボード（PC版）スケジュール編成・各種管理
スマートフォンホーム（スマホ版）訪問予定の確認・現場運用
スマホでもパソコン版の画面を見たいといった切り替えは基本的に不要です。役割に応じて必要な画面が自動で表示されます。

1.4 権限（ロール）の種類

利用者は次の3つの権限のいずれかを持ちます。できる操作・見える画面が権限ごとに異なります。

権限画面の表示名主にできること
管理者管理者すべての操作。ユーザー（アカウント）管理、監査ログ閲覧を含む
マネージャーマネージャー現場運用・スケジュール調整・受け入れ枠の編集など。ユーザー管理は不可
スタッフスタッフ自分の訪問予定の確認、受け入れ枠の閲覧など

詳しい権限の対応表は 付録の権限一覧 を参照してください。

第2部 ログインと初期設定

対象者 全員

2.1 ログイン手順

ログイン方法は ご自身の役割 によって異なります。 訪問スタッフはスタッフコード（例：S002）で、管理者・マネージャーはメールアドレスでログインしてください。

  1. ブラウザで https://carelink.kaipoke-api.net を開きます。
  2. 入力欄の 「メール または スタッフID」 に、メールアドレス または スタッフコード（例：S002）を入力します。
  3. 「パスワード」 に仮パスワード（初回）または自分のパスワードを入力します。
  4. 「ログイン」 ボタンを押します。送信中は「ログイン中…」と表示されます。
  5. ログインに成功すると、パソコンではダッシュボード、スマホではホーム画面が開きます。

2.2 初回ログイン（仮パスワードの変更）

アカウントが新しく作られた直後や、管理者にパスワードをリセットしてもらった直後は、 仮パスワード でログインします。この場合、最初に必ずパスワードの変更画面が表示されます。

  1. 管理者から伝えられた メールアドレス と 仮パスワード でログインします。
  2. 「パスワードの変更が必要です」という画面が自動で表示されます。
  3. 新しいパスワードを入力し、「パスワードを設定」 を押します。
  4. 設定が完了すると、通常の画面（ダッシュボード／ホーム）に進みます。

2.3 パスワードの変更・ログアウト

自分でパスワードを変えたいとき

画面右上のユーザーアイコンのメニューなどから設定画面を開き、現在のパスワード・新しいパスワード・ 新しいパスワード（確認） を入力して 「パスワードを変更」 を押します。変更後は安全のため一度ログアウトされ、 再度ログインが必要になります。

表示されるメッセージ意味・対処

ログアウト

パソコンでは画面右上のユーザーアイコンを押し、「ログアウト」 を選びます。 スマホでは マイページ の下部に「ログアウト」ボタンがあります。

共有のスマホやタブレットを使う場合は、使い終わったら必ず ログアウト してください （他の人に予定が見えてしまうのを防ぐためです）。

2.4 ログインが続く仕組み（参考）

一度ログインすると、しばらくの間は再ログインせずに使い続けられます。利用中に自動で接続が更新されるため、 操作の途中で急にログイン画面に戻ることは通常ありません。長期間放置した後などは、改めてログインを求められる場合があります。

第3部 スマホで使う

対象者 スタッフマネージャー管理者

現場で訪問予定を確認するスタッフ向けの章です。スマホのブラウザ（iPhone は Safari、Android は Chrome）で利用します。

3.1 ホーム画面に追加（アプリのように使う）

毎回ブラウザでアドレスを入力する手間をなくすため、ホーム画面にアイコンを追加しておくと便利です。追加後はアドレスバーのないアプリのような画面で開きます。

iPhone（Safari）の場合

  1. Safari で https://carelink.kaipoke-api.net を開きます。
  2. 画面下の 共有ボタン（□に↑のマーク）を押します。
  3. メニューから 「ホーム画面に追加」 を選びます。
  4. 名前が「CareFlow」になっているのを確認して 「追加」 を押します。

Android（Chrome）の場合

  1. Chrome で同じアドレスを開きます。
  2. 右上の ⋮（メニュー） を押します。
  3. 「アプリをインストール」 または 「ホーム画面に追加」 を選びます。
  4. 確認して追加します。ホーム画面に CareFlow のアイコンができます。

3.4 マイページ・シフト希望の提出

「マイページ」 では、自分のプロフィール（名前・メール・権限）や所属事業所を確認できるほか、次の操作ができます。

  • シフト希望の提出 … 対象の月を選び、希望内容を入力して 「提出する」 を押します。提出済みの履歴は 提出済 / 確認済 のバッジで状態が分かります。
  • 表示設定 … 「コンパクト表示」などの切り替え。
  • ログアウト … 共有端末では使用後に必ず押してください。

第5部 受け入れ枠ページの使い方

閲覧 管理者マネージャースタッフ ／ 編集 管理者マネージャー

「受け入れ枠」は、拠点ごとに 「曜日 × 時間帯」 で新しい訪問をどれくらい受け入れられるかを ○△× の記号で一覧表示するページです。新規の依頼が来たときに「いつなら入れられるか」をすぐ判断するために使います。

画面の説明文：「拠点ごとに全コースを統合した『曜日 × 時間帯』の受け入れ可能枠（おおよその目安）。」
あくまで おおよその目安 です。最終的な可否は担当者が判断してください。

5.2 ○△×の意味（判定の考え方）

○△×は、その拠点の全コースの空き状況から 自動で計算されます。考え方は次のとおりです（移動時間までは細かく見ない、おおまかな目安です）。

記号意味判定のめやす
○ 受け入れ可能 標準的な訪問（60分）がそのまま入る空きがあるコースが1つ以上ある（受け入れ人数・残り時間・連続した空き時間がそろっている）
△ 相談ください 60分まるごとは入らないが、30分以上の部分的な空きはある。時間や内容を調整すれば入れられる可能性
× 枠なし 空きがない／定休日／昼休み／その週のスケジュールがまだ作られていない、のいずれか
1コースの上限は 最大6名・最大480分（8時間）を目安に計算しています。 同じ住所で連続して訪問するケースなどは、まとめて時間を確保したものとして扱われます。

5.5 スマホでの受け入れ枠　マネージャー管理者

スマホでも受け入れ枠を確認できます（マネージャー・管理者のみ、閲覧専用）。 現場ボード上部の 「受け入れ枠」 ボタンから開きます。

第6部 アカウント管理

対象者 管理者 （管理者のみが操作できます）

新しいスタッフにログインアカウントを発行したり、退職者のアカウントを止めたりする操作です。管理者のみが行えます。

6.1 ユーザーの新規作成（アカウント発行）

スタッフアカウント作成のポイント（訪問スタッフの場合）

訪問スタッフのアカウント作成では、スタッフマスタから選択して作成する方法が最も効率的です。 こうすると選んだスタッフのコード（S001など）がログインIDに自動設定され、アカウント作成と同時にスタッフ紐付けが完了します。

  1. PCでログインし、ユーザー管理 画面（/admin/users）を開きます。画面右上の管理者向けボタンからアクセスできます。
  2. 「新規ユーザー」 ボタンを押します。
  3. ロール を 「スタッフ」 に選び、スタッフ選択（既存のスタッフマスタから）を指定します。
    （またはメールアドレスだけで作成し、後から編集画面で紐付けることも可）
  4. 「作成」 を押します。選んだスタッフのコードがログインIDに設定され、仮パスワードが発行され、1度だけ画面に表示されます。
  5. 表示された仮パスワードをメモし、安全な方法で本人へ伝えます（スタッフコードはユーザー一覧でいつでも確認できます）。
仮パスワードは一度しか表示されません。 画面を閉じると二度と見られません。必ずこの場でコピー・控えを取ってから閉じてください。

管理者・マネージャーのアカウント作成

  1. ユーザー管理画面で 「新規ユーザー」 を押します。
  2. メールアドレス を入力し、ロール を「管理者」または「マネージャー」に選びます。
  3. 「作成」 を押します。仮パスワードが自動で発行され、画面に表示されます。
  4. 表示された仮パスワードを コピー し、安全な方法で本人へ伝えます。
本人が初めてログインすると、必ずパスワードの変更を求められます（2.2 参照）。 仮パスワードのままでは使い続けられない仕組みです。

6.2 編集・パスワードリセット・削除

ユーザー一覧の各行から、次の操作ができます。一覧には メール／ロール／スタッフ紐付け／パスワード変更要求／状態 が表示されます。

操作内容
編集（✏️）メールアドレス・ロールの変更、「次回ログイン時にパスワード変更を必須にする」の切り替え
パスワードリセット（🔑）新しい仮パスワードを発行。本人は次回ログイン時にパスワード変更が必須になります。パスワードを忘れた人への対応に使います
削除（🗑️）「{メール} を削除します。よろしいですか？」の確認後に無効化します（退職者など）

6.3 スタッフ（マスタ）とログインアカウントの紐付け

CareFlowでは 「スタッフ情報（マスタ）」 と 「ログインアカウント」 は別々に管理されています。

  • スタッフ（マスタ） … 訪問看護スタッフの氏名・所属・シフトなどの業務情報。
  • ユーザー（アカウント） … ログインのためのスタッフコード（またはメール）・パスワード・権限。

紐付けの役割と必要性

スタッフ本人が「自分の訪問」を見られるようにするには、アカウント作成に加えて 「このアカウントはどのスタッフのものか」を紐付ける 必要があります。紐付けがないと、スマホのホーム画面に 訪問が表示されません。

紐付けの方法

ユーザー管理画面で、対象のユーザー行の 「編集」 を押して編集ダイアログを開きます。

  • スタッフから作成した場合： 既に紐付けが完了。6.1 での「スタッフ選択」を使った方法です。
  • メールアドレスだけで作成した場合： 編集画面の 「スタッフ」 フィールドから、該当するスタッフを選んで紐付けます。
  • 紐付けを解除する： 編集画面でスタッフ選択を空にして保存します（退職時など）。

紐付けのタイミングと注意

シーン説明
新規スタッフの初回ログイン アカウント作成時に紐付けを完了させれば、初回ログイン直後から「自分の訪問」が見えます。
既存スタッフへのアカウント後付け スタッフマスタは昔からあるが、最近になってアカウントを作る場合。編集画面で紐付けします。
既にログイン中の人を紐付けた 反映は最大約1時間、またはログアウト→再ログイン時に即反映されます。 急ぎの場合は本人に一度ログアウト→再ログインを依頼してください。
紐付けの変更時の注意： 既にシステムにログイン中のユーザーを後から紐付けた場合、新しい紐付け情報が見えるまで 最大1時間かかることがあります。 テスト時や緊急時は、本人にログアウト → 再ログインを実施してもらうと即座に反映されます。
