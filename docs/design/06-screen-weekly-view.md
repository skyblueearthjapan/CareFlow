# 06. 画面3：週ビュー（中核画面・Warm & Human）

CareLink の中核画面。患者の固定枠 + スタッフ割当を一画面で確認・編集。

## 6-1. 概要

- URL: `/weekly?week=2026-W18`
- アクセス: admin / staff（staff は自分関連のみ）
- 役割: スケジュール全体の把握 + 部分編集 + 割当実行への入口
- 設計指針: 1画面で完結、ドラッグドロップ、モーダル多用

### セルの状態表示（4種）

| 値 | 円アイコン色 | ラベル |
|---|---|---|
| `null` | なし | — |
| `fixed` | `--brand-primary` (teal) | 固定 |
| `am` | `#92400E` on `#FEF3C7` | 午前 |
| `pm` | `#9A3412` on `#FFEDD5` | 午後 |
| `all` | `#9D174D` on `#FCE7F3` | 終日 |

### インタラクション
- セルクリック: 値が null → fixed、fixed → null
- セル長押し（450ms）: 値を fixed → am → pm → all → fixed... 循環
- 通常週/特別週切替: 上部のラジオで完全に別データに切替
- 特別週時: 適用週バナー + 「特別週を解除」ボタン
