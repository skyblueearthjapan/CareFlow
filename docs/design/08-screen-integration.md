# 08. 画面5：連携センター（Warm & Human）

割当実行 + カイポケ自動操作 + 差分管理 + ジョブ履歴を1画面に集約。

## 8-1. 概要

- URL: `/integration`
- アクセス: admin のみ
- 役割: 「自動化された一連の作業をユーザーが任意に進められる場所」
- 設計指針: 「使い勝手が悪ければ意味がない」原則を最重視

### ジョブヘッダー Spec
- 種別 Badge: apply=info / expand=event / export=neutral
- 時刻: 12.5 / `--text-secondary` / tnum / min-width 150
- 件数: 13 / 500
- 状態: Badge success dot
- カウント: `--success` ✓ / `--error` ✗ / `--text-muted` ⊘
- 右端: ChevronUp/Down 16

### 明細行
- ステータスアイコン: 14 / 種別色
- 「成功」「失敗」「スキップ」: 12.5
- 失敗時:
  - エラーメッセージ: 12 / `--text-muted` / margin-top 2
  - 操作: padding-top 6, gap 8
    - チェックボックス「手動対応済」(12 + accentColor teal)
    - 「📷 スクショ」 (12 / `--brand-primary`) — クリックで画像モーダル
    - 「+ メモ」 (12 / `--brand-primary`) — クリックでテキスト入力フィールド表示

### 手動対応済の見た目変化
通常時:
```
✗ 山田 花子 5/5 編集 失敗
   エラー: セレクタ取得失敗
   [☐ 手動対応済] [📷スクショ] [+ メモ]
```

ON 後:
```
✓✏ 山田 花子 5/5 編集 [手動対応済]
   「カイポケに手動で入力済」  2026-05-04 15:30 (川原様)
   [☐ 取り消す]
```

→ **「未対応の失敗だけに集中」**できる状態を作る。

### フィルタ
- 「失敗のみ表示」: 失敗かつ未手動対応のみ
- 「手動対応済を除く」

### CSV出力
- ジョブ単位 / 明細単位
- 列: 日付・患者名・アクション・結果・エラー・スクショURL・手動対応済・メモ

## 8-10. データソース

すべて CareLink Backend 経由（Frontend は kaipoke-api を直接叩かない）。

| API | 用途 |
|---|---|
| `GET /api/integration/status` | ① ステータス |
| `POST /api/integration/expand` | ② 月間展開 |
| `POST /api/integration/export` | ② CSV出力 |
| `POST /api/integration/diff` | ② 差分検出 |
| `POST /api/integration/apply` | ② 差分適用（非同期） |
| `GET /api/integration/jobs/{id}` | ③ 進捗ポーリング |
| `POST /api/integration/jobs/{id}/stop` | ③ 中断 |
| `GET /api/integration/vnc-url` | ④ VNC URL（Bearer Token必要） |
| `GET /api/integration/correction-sheets/latest` | ⑤ 差分プレビュー |
| `PATCH /api/integration/correction-items/{id}` | ⑤ include/comment 更新 |
| `GET /api/integration/jobs?limit=20` | ⑥ 履歴 |
| `PATCH /api/integration/job-items/{id}` | ⑥ manually_handled 更新 |
