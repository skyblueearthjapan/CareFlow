# 04. 画面1：ログイン（Warm & Human）

NextAuth.js + メール+パスワード認証。Warm な雰囲気でハートロゴ＋セリフ書体。

## 4-1. 概要

- アクセス: 未認証ユーザー（`/login`）
- 認証成功後: `/dashboard` または直前のURLへ
- 失敗時: 同画面にエラーバナー

## 4-7. インタラクション

### 入力バリデーション
- メール形式: 標準 regex
- パスワード: 8文字以上
- 空欄送信時: フィールド下に赤エラーメッセージ

### ログイン処理
1. 「ログイン」ボタン押下 → loading 状態（スピナー）
2. NextAuth.js `signIn('credentials', {email, password})`
3. 成功 → `/dashboard` リダイレクト
4. 失敗 → エラーバナー

### エラー表示
```
┌──────────────────────────────────┐
│  ✗ メールまたはパスワードが       │
│     正しくありません              │
└──────────────────────────────────┘
赤背景・赤文字、フォーム上部に表示
```

### パスワード表示切替
- 👁 (Lucide Eye) クリック → type="text" 切替
- もう一度クリック → type="password" に戻す

### Remember me
- ON: セッション有効 30日
- OFF: 24時間

---

## 4-8. アクセシビリティ

- email: `autocomplete="email"`、`type="email"`
- password: `autocomplete="current-password"`、`type="password"`
- フォーム送信: Enter キー対応
- フォーカス順: メール → パスワード → 表示切替 → 保持 → ログイン
- aria-label: 各フィールドに明示

---

## 4-9. データフロー

```
[ログイン画面]
   ↓ ユーザー入力
[NextAuth.js Credentials Provider]
   ↓ POST /api/auth/callback/credentials
[CareLink Backend]
   ↓ Users テーブル検索 (email)
   ↓ bcrypt.compare(password, hash)
   ↓ 成功 → JWT 発行
[Cookie 保存（httpOnly）]
   ↓
[/dashboard リダイレクト]
```

### 失敗時
- bcrypt 不一致 → 同一メッセージ「正しくない」
- ユーザー不在 → 同上（情報漏れ防止）
- レート制限 → 5回失敗で15分ロック
