## 5-5. SummaryCard（3つ並列）

```
┌─ Card (padding 20, radius 16, shadow-sm) ─┐
│ 今週の訪問              ┌──────┐          │ ← title + アイコンチップ
│ (12.5 / 500 / secondary)│  📅  │          │   32×32 / radius 8
│                          └──────┘          │   bg: var(--brand-primary-50)
│                                            │   color: var(--brand-primary)
│ 85件                                       │ ← 数字: Serif 38/700 + tnum
│ (Serif 38)  (13/muted)                     │   ライン下マージン 14
│                                            │
│ ● 80件 割当済 (success)                    │ ← サブ: 11.5 / secondary + 6px dot
│ ● 5件 未割当 (error)                       │
└────────────────────────────────────────────┘
```

### 3つのカード

| タイトル | 数値 | アイコン | サブ | クリック先 |
|---|---|---|---|---|
| 今週の訪問 | 85 件 | Calendar | success/error 件数 | `/weekly` |
| 割当待ち | 5 件 | AlertCircle (warning) | 要対応 | `/weekly` |
| カイポケ同期 | 2 時間前 | Refresh | 成功/失敗 + 「今すぐ確認 →」 | `/integration` |

### staff ロール時
- 「今週の訪問」のみ（自分担当のみ）。他2つは非表示。
- grid: `1fr` に変更。

### アラート行の Spec
- padding: 12px 0
- gap: 12px
- 左端: Badge (tone: error / special / warning) with dot
- 中央: 説明 (12.5 / secondary)
- 右: 件数 (18 / 700 / tnum) + 「件」(11 / muted)
- 矢印: Lucide ChevronRight 16 / muted

### クイックアクションボタン
- grid 2×2、gap 8px
- padding: 12px 14px
- radius: 8
- primary 1個（AI入力）+ 通常3個
- 通常: 背景 `--bg-surface`、border `--border-default`
- 13/500、左寄せ

## 5-8. ロール別表示差異

### admin
- 全カード表示
- アラートは全スタッフ・全患者対象
- アクティビティは全ユーザー履歴

### staff
- 「今週の訪問」のみ表示（自分の担当）
- 「割当待ち」「カイポケ同期」非表示
- アラート: 自分関連のみ
- アクティビティ: 自分の操作のみ
- クイック: 「患者追加」「カイポケ連携」非表示

## 5-9. データソース

| 表示 | API |
|---|---|
| 今週の訪問件数 | `GET /api/visits/summary?week=current` |
| 割当待ち | `GET /api/visits/unassigned?week=current` |
| カイポケ同期 | `GET /api/kaipoke/status` |
| アラート | `GET /api/alerts` |
| アクティビティ | `GET /api/activity?limit=5` |

更新: ページ表示時に取得。1分ごとに自動更新（カイポケ同期）。
