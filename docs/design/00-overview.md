# CareLink UI デザイン仕様書（インデックス）

訪問看護スケジューリングアプリ CareLink のUI設計ドキュメント。
**Warm & Human**（クラウドデザインで採用された案A）を全面採用したデザイン仕様書です。

## デザインの根本トーン

| 軸 | 方針 |
|---|---|
| 雰囲気 | 温かく・人間的で・落ち着いた医療現場 |
| 主色 | **ティール `#0D9488`**（信頼・癒し） |
| 副色 | **テラコッタ `#D97706`**（柔らかいアクセント） |
| 背景 | **クリーム `#FAF7F2`**（紙の質感） |
| 見出し | **Noto Serif JP**（和の品格） |
| 本文 | **Noto Sans JP**（読みやすさ） |
| 形 | 大きめの角丸（10〜20px）、柔らかい多層シャドウ |
| アイコン | Lucide系の線アイコン（ハートロゴ含む） |

## 設計の基本原則

1. **シンプルさ最優先** — 1画面で完結／遷移最小化／応答即時
2. **超統合型** — 22機能を4画面 + グローバル + モバイルに圧縮
3. **使い勝手重視** — 「使い勝手が悪ければ意味がない」
4. **横展開可能** — 他事業所でも使えるレベル
5. **Warm & Human** — 業務ツールであっても人間的な温かさを

## 技術スタック前提

- Frontend: Next.js + TypeScript + Tailwind CSS + shadcn/ui
- Backend: FastAPI + SQLAlchemy 2.0
- DB: PostgreSQL
- Mobile: PWA
- 音声: Web Speech API + Gemini API
- 認証: NextAuth.js + メール+パスワード
