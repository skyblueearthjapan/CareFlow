# 10. モバイル専用画面（Warm & Human）

PWA 前提。スタッフが移動中・訪問先で素早く参照・入力する画面群。

## 10-1. 概要

- アクセス: admin / staff（staff利用が中心）
- 配信: PWA（ホーム追加可）
- 役割: 「移動中・訪問先」シーン最適化
- 設計指針: タッチ前提、音声入力中心、最小限の情報

---

## 10-2. モバイル画面構成

```
[ボトムナビ 4タブ]
🏠 ホーム      → モバイルホーム（ウェルカム+統計）
📅 今日        → 今日の訪問（カード式）
📅 今週        → 週ビュー縦スクロール
👤 マイページ  → スタッフ自身の情報・設定
```

## 10-9. モバイルでの権限と機能差

### 表示差
- staff: 自分関連の訪問・シフトのみ
- admin: モバイルでも全体閲覧可能だが、編集はPC推奨

### 操作差
- 訪問の詳細編集: PC推奨（モバイルでは閲覧 + 簡易ステータス変更のみ）
- マスタ管理: モバイル簡易表示、編集はPC推奨
- 連携センター: モバイルは閲覧のみ、実行はPC推奨

```json
    {"src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png"},
    {"src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png"},
    {"src": "/icons/icon-maskable.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable"}
  ]
}
```

### Service Worker
- 静的アセット (HTML/CSS/JS/フォント) のみキャッシュ
- API はリアルタイム（キャッシュしない）
- プッシュ通知: 将来検討

### ホーム画面追加
- iOS Safari: 共有 → 「ホーム画面に追加」
- Android Chrome: 自動プロンプト
- 起動時スプラッシュ: ハートロゴ + クリーム背景

## 10-11. タッチ最適化

- ボタン最小 44×44px
- タップ間隔 8px 以上
- タップフィードバック: 100ms 薄背景 / scale 0.98
- pull-to-refresh: 主要リスト画面
- スワイプジェスチャ: 戻る (左端→右)
- キーボード: 数値=numeric / メール=email / 時刻=ネイティブピッカー

---

## 10-12. モバイル固有の制約

### 画面幅
- 320px〜（小iPhone対応）
- 縦向き優先（横向きはオプション）

### マイク
- HTTPS 必須
- iOS Safari: ユーザー操作からのみ録音可
- 権限拒否時のフォールバック必須

### バッテリー
- バックグラウンド処理最小限
- ロケーション・センサー不使用

## 10-13. データソース

すべて PC と共通 API。

| 画面 | API |
|---|---|
| モバイルホーム | `GET /api/visits/today`, `GET /api/alerts` |
| 今日 | `GET /api/visits/today?staff_id=me` |
| 今週 | `GET /api/visits?week=current&staff_id=me` |
| マイページ | `GET /api/me`, `GET /api/staff/{me}/shift` |
| AI入力 | `POST /api/ai/interpret` |
