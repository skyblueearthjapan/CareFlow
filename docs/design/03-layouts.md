# 03. 共通レイアウト（Warm & Human）

CareLink の全体構造。**サイドバーとメインを1つの大きな丸カードに統合**したのが Warm & Human の特徴。

---

### 外枠カードの Spec

```css
{
  background: var(--bg-base);            /* 白 */
  border-radius: 20px;
  border: 1px solid var(--border-default);
  box-shadow: 0 1px 2px rgba(28,25,23,0.04),
              0 8px 24px rgba(28,25,23,0.05);
  display: flex;                          /* サイドバー + メインを横並び */
  overflow: hidden;
  margin: 14px;                           /* 外側に余白（クリーム背景が見える） */
}
```

→ サイドバーとメイン領域が **1枚のカード**にまとまり、外側だけ丸い。

## 3-3. PC サイドバー詳細

### 展開時 (232px)

```
┌────────────────────────┐
│ ┌──┐ CareLink           │ ← ブランド領域（高さ60px、Header下罫線と揃う）
│ │♡ │ 稲毛 訪問看護      │
│ └──┘                    │
├────────────────────────┤
│ メニュー                 │ ← 11px / 600 / uppercase / muted
│                         │
│  🏠 ダッシュボード       │
│ ┃📅 週ビュー            │ ← アクティブ：青背景＋ティール文字
│  📋 マスタ管理           │
│  🔄 連携センター         │
│                         │
│         （flex spacer）  │
│                         │
│ ┌──────────────────┐    │
│ │ 今日の訪問         │    │ ← フッターカード
│ │  17件 (Serif 28)  │    │
│ │ 完了 5 / 残り 12  │    │
│ └──────────────────┘    │
├────────────────────────┤
│ ┌──┐                    │
│ │川│ 川原 様             │ ← ユーザー情報フッター
│ └──┘ admin              │
└────────────────────────┘
```

### 折りたたみ時 (72px)

```
┌────┐
│ ┌─┐│
│ │♡││
│ └─┘│
│ CL │ ← Serif 9px（縦積み）
├────┤
│    │
│ 🏠 │
│ 📅 │ ← アクティブ
│ 📋 │
│ 🔄 │
│    │
├────┤
│ 川 │ ← アバターのみ
└────┘
```

### Spec

#### ブランド領域
- 高さ **60px**（Header と完全一致）
- border-bottom: 1px `--border-default`
- 展開時: padding 0 18px、横並び
- 折りたたみ時: 縦積み中央寄せ
- ロゴ: 36×36 (展開) / 30×30 (折りたたみ)、radius 10、`linear-gradient(135deg, var(--brand-primary), #14B8A6)`、白いハートアイコン中央
- ロゴの shadow: `0 4px 12px rgba(13,148,136,0.25)`
- ワードマーク: Serif 18px / 700（展開時）、Serif 9px / 700（折りたたみ時、letter-spacing 0.04em）
- サブタイトル: 10px / `--text-muted`「稲毛 訪問看護」（展開時のみ）

#### メニューセクション
- 見出し「メニュー」：8px 6px 6px / 10px / 600 / uppercase / `--text-muted`（展開時のみ）
- アイテム: 11px 14px (展開) / 11px 0 中央寄せ (折りたたみ)
- radius **12px**
- アクティブ: 背景 `--brand-primary-light` (薄ティール)、文字 `--brand-primary`、weight 600、アイコン strokeWidth 2.2
- 非アクティブ: 文字 `--text-secondary`、weight 500
- staff ロール: マスタ・連携を非表示（先頭2項目のみ）

#### 「今日の訪問」フッターカード（展開時のみ）
- 背景: `--bg-app` (cream)
- radius: 14
- padding: 14
- ラベル「今日の訪問」: 11px / `--text-muted`
- 数字: Serif **28px** / 700 / `--brand-primary` / tabular-nums
- サブ「完了 5 / 残り 12」: 10.5px / `--text-muted`

#### ユーザーフッター
- border-top: 1px `--border-default`
- アバター: 32×32 円形、ティールgradient、白文字
- 名前: 13px / 600
- ロール: 11px / `--text-muted`

### サイドバー切替アニメ
- 200ms ease（width transition）
- shouldShow logic：text 要素は collapsed=true で非表示

## 3-7. AI入力 FAB

PC・モバイル共通の右下フローティング。

```
[PC]                          [モバイル]
              ┌─────┐                       ┌─────┐
              │  ✦  │                       │  ✦  │
              └─────┘                       └─────┘
              right: 28px                   right: 16px
              bottom: 28px                  bottom: 88px (ナビ上)
              60×60                         64×64
```

### Spec
- background: `linear-gradient(135deg, var(--brand-primary), #14B8A6)`
- color: `#FFFFFF`
- アイコン: Lucide Sparkles size 22 / strokeWidth 2
- shadow: `0 8px 24px rgba(13,148,136,0.40), 0 0 0 6px rgba(13,148,136,0.10)`
- z-index: 20
- hover: scale(1.05) 200ms
- ショートカット: `Cmd/Ctrl + K` で開く

## 3-8. レスポンシブ動作

| 画面幅 | レイアウト |
|---|---|
| ~767px | モバイル：ボトムナビ + 1カラム |
| 768~1023px | タブレット：サイドバー折りたたみ + 通常ヘッダー |
| 1024~1379px | PC：サイドバー展開可能 |
| 1380px~ | PC ワイド（最適化フレーム） |
