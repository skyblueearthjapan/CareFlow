# 09. グローバル：AI入力フローティング（Warm & Human）

全画面右下に常駐するティールgradient FAB → AI入力モーダル。テキスト・音声で休み・イベント・キャンセル等を自然言語で入力。

## 9-1. 概要

- アクセス: admin / staff
- 起動: 右下 FAB / `Cmd/Ctrl + K`
- バックエンド: Gemini API
- 出力: AI承認モーダル → DB反映

---

## 9-2. AIに任せる範囲

| # | 機能 | 例 |
|---|---|---|
| 1 | スタッフのその週だけの休み | 「田中さん木曜休み」 |
| 2 | スタッフのイベント | 「火曜午後 管理者会議」 |
| 3 | 訪問キャンセル・延期 | 「山田さん明日キャンセル」 |
| 4 | 突発訪問追加 | 「鈴木さん明日10時に1時間追加」 |
| 5 | モバイル音声入力（上記すべて対象） | （音声で同上） |

---

## 9-3. フロー全体

```
[全画面]
   │
   ▼
[FAB クリック / Cmd+K]
   │
   ▼
[AI入力モーダル開く]
   ├─ テキスト入力
   ├─ 音声入力（録音 → Web Speech API でテキスト化）
   │
   ▼
[「送信」クリック]
   │
   ▼
[Backend → Gemini API]
   │ プロンプト + 入力 → 構造化 JSON
   │
   ▼
[AI承認モーダル] ← 解釈結果を表示
   ├─ 「手動で修正」
   ├─ 「キャンセル」
   ├─ 「登録」 → DB → Toast → 閉じる
   │
   ▼
[該当画面に反映]
```

## 9-8. action_type 一覧

| action_type | 説明 |
|---|---|
| `staff_weekly_override` | スタッフのその週だけの休み |
| `staff_event` | スタッフのイベント |
| `visit_cancel` | 訪問キャンセル |
| `visit_postpone` | 訪問延期 |
| `visit_add` | 訪問追加 |
| `unknown` | 解釈失敗 |

## 9-12. データソース

| API | 用途 |
|---|---|
| `POST /api/ai/interpret` | 自然言語 → 構造化 JSON 解釈（Gemini中継） |
| `POST /api/staff-weekly-overrides` | スタッフ休み登録 |
| `POST /api/staff-events` | スタッフイベント登録 |
| `POST /api/visits` | 訪問追加 |
| `PATCH /api/visits/{id}` | 訪問キャンセル・延期 |

`/api/ai/interpret` は CareLink Backend が Gemini API を中継するエンドポイント。
スタッフ・患者一覧をプロンプトに自動注入。

## 9-13. 音声入力の技術

- **Web Speech API**（ブラウザ標準）
- 言語: `ja-JP`
- 連続認識: ON
- HTTPS 必須
- iOS Safari は ユーザー操作からのみ可能

### マイク権限拒否時
```
⚠ マイクへのアクセスが許可されていません
   ブラウザ設定で許可するか、テキストで入力してください
```

### ブラウザ非対応時
```
ℹ このブラウザは音声入力に対応していません
   Chrome / Edge / Safari をお使いください
```
