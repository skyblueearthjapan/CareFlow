# 07. 画面4：マスタ管理（Warm & Human）

患者・スタッフ・拠点・市区町村の4タブを切替で管理。Master-Detail（左：一覧、右：詳細）構成。

## 7-1. 概要

- URL: `/master?tab=patient`
- アクセス: admin のみ
- 役割: マスタCRUDをまとめて1画面で
- 設計指針: シンプル、左に一覧 + 右に詳細、新規追加・編集はインライン

## 7-6. 患者の各セクション

### 1. 基本情報
- 名前 (input)
- フリガナ (input)
- 性別 (radio表示・固定)
- 状態 (Badge dot: 稼働/休止/入院/未開始)
- 保険区分 (Badge medical or care)

### 2. 住所・拠点
- 住所 (input)
- 緯度経度 (12 / `--text-secondary` / tnum) — 「(自動)」表記
- 優先拠点 (Badge info)
- 許容拠点 (chips配列 + 「+ 追加」ボタン 11/teal)

### 3. 訪問条件
- 性別制限 (radio: なし / 女性のみ / 男性のみ)
- 必要スタッフ数 (radio: 1名 / 2名)
- NG時間帯 (start-end or "—")

### 4. 通常週パターン  → アクション「カレンダーで編集 →」
- 設定中の枠を tnum で列挙
- クリック → PatientWeeklyPatternModal（`06-screen-weekly-view` § 6-7）

### 5. 特別週パターン（あれば表示）
- 適用週 (Badge special dot) 例：「第18週 (4/27-5/3)」
- 「編集 →」リンク

### 6. 備考（オプション）
- textarea

## 7-11. インタラクション

### 新規追加
1. 「+ 追加」 → 詳細パネルが空フォームに切替
2. 必須項目入力 → 「保存」 → 一覧に追加 + Toast成功

### 編集
1. 一覧から行クリック → 詳細表示
2. 編集 → 「保存」 → Toast成功

### 削除
1. 「🗑 削除」 → 確認モーダル「本当に削除しますか？」
2. 削除確定 → 論理削除（過去訪問データは保持）+ Toast

### 未保存遷移警告
- フォーム編集中で別行/別タブ/離脱 → 「保存しないで離れますか？」確認
