# 休み・勤務表の表を広くする（2026-11-01）

## 目的
`/admin/leave` の表が狭く見づらい（PO）。右の「申請中／カイポケとの差分」の欄（340px）が常に幅を取り、表は 15 日分ほどしか見えず横に送る必要がある。マスも詰まっていて、行も低い。

PO の選んだ配置：**右の欄を表の上の帯へ移し、表を全幅にする。** 行の高さと列の幅も広げる。

## 変える場所（画面だけ・API と DB は変えない）
- `frontend/app/(app)/admin/leave/page.tsx`
  - `xl:grid-cols-[minmax(0,1fr)_340px]` の 2 列をやめ、表のカードを全幅にする。
  - 「申請中（N）」「カイポケとの差分」のタブを、表の上の帯にする。ふだんは閉じていて、押すと帯の下に開く（もう一度押すと閉じる）。
  - 申請中が 1 件以上あるときは、件数を目立たせる（色付きの数字）。開いた中身は今の `LeavePendingPanel`・`LeaveComparePanel` をそのまま使う。
  - 説明文の「右の『申請中』」を「上の『申請中』」に合わせる。
  - ほかの画面から申請中へ飛んでくる経路（URL の指定・`openCellFor` など）で、帯が自動で開くこと。
- `frontend/components/leave/LeaveSheetGrid.tsx`
  - 行の高さと列の幅を広げる（目安：日の列 28〜32px → 40px 前後、行 46px → 56px 前後）。名前の列は今のまま。
  - マスの中の「休」「足」「○」「件数」が重ならないよう配置を合わせる。
  - 画面の幅が足りないときは、今と同じく横に送れる。職員の列は左に固定したまま。

## 試験の観点
- 既存の `page.test.tsx`・`components/leave/__tests__` が通る（文言の変更に合わせて試験も合わせる）。
- 帯の開け閉め、申請中の件数の表示、申請中からマスへ飛ぶ動き、承認の操作が今どおり動く。
- 実際の画面で、1920px 幅（拡大 100%）と 75% 表示で見え方を確かめる。

## リスク
- 申請を処理しながら表を見る使い方では、帯を開くと表が下へずれる。開いた中身に高さの上限を付け、中で送れるようにする。
- 表のマスを広げると、狭い画面では横に送る量が増える。
