# 登録の位置のずれに気づいて、管理者がボタンで合わせる（設計メモ・2026-10-17）

## 1. きっかけ
- 10/17、患者様 6 人の登録座標が、職員が実際に QR を読んだ場所から 120〜830m ずれていた。モニターでは毎回「不一致」「要確認」になっていた。
- このときは開発者が本番 DB を直接書き換えて合わせた（打刻位置の中央値に合わせ、`geocoding_cache` も同じ値にした）。
- PO の指摘: 他の事業所へ広げると、開発者は各事業所の DB を触れなくなる。**各事業所の管理者が、画面の中で自分で合わせられる**ようにする。

## 2. PO の決定
- 形は「**らく助が気づいて知らせる＋管理者がボタンで合わせる**」。全自動にはしない。
- 合わせた記録を残し、［元に戻す］を付ける。

## 3. ずれの見つけ方（サーバー）
患者ごとに、次の打刻を集める。
- `visit_checkins` のうち、その患者で `checkin_source='qr'`、緯度経度あり、GPS 精度 ≤ 100m（精度が無い行は数える）
- 直近 60 日、新しい順に最大 20 件

候補の位置 = 緯度・経度それぞれの中央値。その点から 50m 以内の打刻を「まとまり」とする。

次の条件がすべてそろったら「ずれ」とする。
1. まとまりが **3 件以上**
2. まとまりの打刻が JST で **2 日以上**に分かれている
3. まとまりが集めた打刻の **6 割以上**（職員がよそで読んだ打刻が混ざっても引っ張られないように）
4. 提案の位置 = まとまりの中央値。これが登録座標から **match_m（100m）より遠い**。登録座標が無い患者は距離なしで提案する。

返す値: `{distance_m | null, suggested_lat, suggested_lng, scans, days}`。

## 4. API（admin のみ）
- `GET /patients/{id}/location-drift` → 上の値。ずれが無ければ `null`。
- `POST /patients/{id}/location/align` → サーバーで計算し直して合わせる（画面から座標は受け取らない）。ずれが無くなっていたら 409。
  - `patients.lat/lng` を更新する。
  - 住所の `geocoding_cache`（`address_hash(address)`）があれば、同じ値にする（住所を保存し直したときに古い位置が戻らないように）。
  - `audit_logs` に before/after（座標）を残す。
- `POST /patients/{id}/location/revert` → 直近の align の before に戻す（cache も）。戻した記録も残す。直近の align が無ければ 404。
- 訪問モニター: `MonitorVisit.location_drift`（上と同じ形・**admin にだけ**入れる）。その日の患者分を 1 回のクエリでまとめて計算する（訪問ごとに問い合わせない）。

## 5. 画面
訪問モニターの訪問の詳細（住所の行の下）と、患者画面に出す。admin だけ。
```
⚠ 登録の位置が、実際に QR を読んだ場所と約 440m 離れています（打刻 6 回・3 日分）
   [打刻の場所に合わせる]  [地図で見比べる ↗]
```
- ［地図で見比べる ↗］は、登録の位置から提案の位置までの Google マップの経路を開く。2 点と距離が一度に見られる。
- ［打刻の場所に合わせる］を押すと、確認のダイアログを出す。「次の打刻から、この位置で判定します。過去の打刻の判定は変わりません」と書き、［合わせる］で実行する。
- 済んだら toast「登録の位置を合わせました」に［元に戻す］を付ける。モニターと患者は再取得する。
- 文言は「合わせる」を使う（「直す・修正」は使わない）。

## 6. 範囲外
- 全自動で合わせること（PO が選ばなかった）。
- 地図上でピンを手で動かすこと。

## 7. 試験
- BE:
  - 条件の境目（2 件・1 日だけ・6 割未満・100m 以内は出ない）
  - 精度が悪い打刻は数えない
  - align で patient と cache の両方が変わり、audit が残る
  - revert で元に戻る
  - staff は 403
  - モニターは admin だけに `location_drift` を入れる
- FE:
  - admin にだけ出る
  - 押すと確認が出て、［合わせる］で API を呼ぶ
  - ［元に戻す］
  - 経路リンクの URL
