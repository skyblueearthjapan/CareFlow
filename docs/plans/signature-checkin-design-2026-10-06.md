# QR を置けない利用者さんの「サインで記録」— 設計たたき台

作成: 2026-10-06 ／ ステータス: **PO の決定を反映（2026-10-06）・モック前・未実装** ／ 関連: `actual-time-adjust-design-2026-09-30.md`（実績の時刻を合わせる）・`pc-actual-time-edit-design-2026-10-06.md`（PC から合わせる）

## 0. 目的（PO 2026-10-06）
- QR カードを置かせてもらえない利用者さんがいる。スマホ・タブレットに**大きなサイン欄**を出し、**サインをもらった時刻と GPS の位置**を記録して、QR の読み取りと同じ扱いにしたい。
- サインは到着・退出の 2 回はもらえないので 1 回だけ。もう片方の時刻をどう残すか、時刻の調整をどこでするかも決めたい。
- 「GPS で訪問先にいたこと」＋「その場で利用者さんのサインがあること」で、QR と同等以上に確か。

## 1. 今あるもの（コード調査 2026-10-06）
| 項目 | 今 |
|---|---|
| QR なしの記録 | **スマホに「QRなしで記録」ボタンが既にある**（`QrScanner.tsx`）。GPS を取り、距離の確認を見せてから、時刻と位置で到着・退出を記録する（`checkin_source='manual'`・打刻履歴では「QRなし」）。担当外の代行では出ない |
| 位置の判定 | 利用者さんの住所の座標との直線距離。100 m 以内=一致／300 m 以内=要確認／それより遠い=不一致（設定で変えられる）。**不一致でも記録は断らない**（通知と印。到着は理由が要る） |
| 記録の区分 | `visit_checkins.checkin_source` は `'qr'` / `'manual'` だけ（DB の CHECK あり） |
| 圏外 | スマホにためて後で送る（localStorage・JSON のみ）。**画像は入らない** |
| ファイルの置き場 | 音声記録・写真はサーバーのディスク（`/opt/carelink/data/...`）。音声は 90 日で中身を消す・取り出しは監査ログに残す |
| 利用者マスター | QR の発行（`patients.qr_token`）だけ。**記録の方法の設定は無い** |
| 時刻の調整 | 「実績の時刻を合わせる」（スマホ: 本人・7 日以内／PC: 打刻履歴）。サインの記録にもそのまま使える |

## 2. おすすめの運用: 「サインは 1 回、時刻は 2 回とも、その場で」
| 場面 | 操作 | 記録されるもの |
|---|---|---|
| **到着** | 「到着を記録」を 1 回押す（今の「QRなしで記録」と同じ・利用者さんの手は借りない） | 押した時刻・GPS・距離の判定 |
| **退出** | **大きなサイン欄**に利用者さん（またはご家族）がサイン →「サインして退出を記録」 | サインした時刻・GPS・距離の判定・**サインの画像** |

- 到着も退出も「その場で押した時刻」が残るので、**後から時刻を作る必要がほぼ無い**。サイン 1 回のあとに時刻を編集する運用は、時刻を後から作れてしまい、QR と同じ確かさが出にくい（調整は押し忘れのときだけ・既存の「合わせる」で。調整は「調整」の印と読取時刻が残る）。
- サインを**退出**でもらう理由: 訪問が終わったことの確認になる（サービス提供の確認に近い）・到着時は玄関先で慌ただしい。到着でもらう運用も設定で選べるようにはできる（§5 Q1）。

## 3. 画面（スマホ・タブレット）
- 訪問の詳細: 利用者さんの記録の方法が「サイン」なら、QR を読むボタンの代わりに **「到着を記録」**／**「サインして退出」** を大きく出す。
- サインの画面: 全画面の白いサイン欄（横向きにも対応）・「消してもう一度」「サインして記録」・署名した人（**ご本人／ご家族／その他**）を選ぶ・日時と利用者名を上に表示。押した瞬間の時刻と GPS を取る。
- 位置が離れていたとき: QR と同じ扱い（記録はする・要確認の印・不一致なら理由）。
- 圏外: 記録（時刻・GPS）はすぐ端末にためて、サインの画像も端末（IndexedDB）にためる。つながったら送る。
- 押し忘れ・後から: 既存の「実績の時刻を合わせる」。サインの記録は消せない（取り消しは管理者のみ・記録が残る）。

## 4. データ・サーバー（案）
- `visit_checkins.checkin_source` に **`'signature'`** を足す（マイグレーションで CHECK を変更）。到着のボタンは今の `'manual'` のまま（または `'gps'` を足して「QRなし」と分けるか → Q2）。
- 新しい表 **`visit_signatures`**: 訪問・打刻（退出）の ID・画像の置き場所・形式（PNG）・大きさ・署名した人の区分・端末の時刻・作成者・作成日時・ハッシュ（改ざん確認）・削除日時。
- 画像はサーバーのディスク（`/opt/carelink/data/visit_signatures/年/月/ID.png`・音声と同じ流儀）。1 枚 数十 KB。
- 取り出し: 管理者は全部・スタッフは自分の当日分だけ（案）。取り出しは監査ログに残す。
- 利用者マスターに **「記録の方法: QR／サイン」** を足す（既定 QR）。サインの利用者には QR カードを発行しなくてよい。
- 表示: 打刻履歴・Excel・A4 の備考に「サイン」、詳細でサインの画像を見られる。訪問モニターにも「サイン」の印。A4 の注記「QR を読み取った時刻です」を「QR・サインの時刻です」に。
- 保存期間: サインの画像は**記録の保存年数に合わせる**（GPS は今 730 日で消している。サインは別に決める → Q5）。

## 5. 決めたいこと
| # | 論点 | 案 |
|---|---|---|
| Q1 | サインは退出でもらうか、到着でもらうか | **退出（おすすめ）**。利用者さんごとに選べるようにもできる |
| Q2 | 到着のボタンの記録の区分 | 今の「QRなし」と同じ（`manual`）でよいか、「サイン利用者の到着」として分けるか |
| Q3 | サインの利用者を決める方法 | **利用者マスターで「サイン」に設定した方だけ**（おすすめ）／すべての利用者で選べる |
| Q4 | 署名した人 | ご本人／ご家族／その他（氏名の入力は任意） |
| Q5 | サインの画像の保存期間 | 記録の保存年数（例: 5 年）／GPS と同じ 2 年 |
| Q6 | サインの画像を見られる人 | 管理者は全部・スタッフは自分の当日分だけ |
| Q7 | PC の帳票（A4・Excel）にサインの縮小画像を載せるか | 載せない（詳細で見る）／A4 だけ載せる |
| Q8 | タブレットの共用 | 職員ごとのスマホが前提。共用タブレットならログインの切り替えが要る |

### 5-1. PO の決定（2026-10-06）
| # | 決定 |
|---|---|
| Q1 | **サインは退出のときにもらう**。到着は「到着を記録」ボタン（時刻＋GPS） |
| Q2 | 到着は今の「QRなし」と同じ扱い（`manual`）。**表示は 到着＝「QRなし（サイン）」・退出＝「サイン」**（PO 確定。ただの QR 忘れの「QRなし」と見分ける） |
| Q3 | **すべての利用者さんで、その場で QR かサインを選べる**（利用者マスターの設定は不要。QR を置けない方も、QR を忘れたときも使える） |
| Q4 | **署名した人は記録しない**（サインの画像だけ） |
| Q5 | **サインの画像は 5 年保存**（それを過ぎたら画像を消す・記録の行は残す） |
| Q6 | **管理者も職員も、期間の制限なく見られる**（当日も過去の日も）。取り出しは監査ログに残す |
| Q7 | **A4・Excel には載せない・備考に「サイン」の印だけ**。画像は画面の詳細で見る |
| Q8 | **すでに iPad などのタブレットで使っている** → タブレット（大きな画面）を前提にサイン欄を作る。共用かどうかは今のログインの運用どおり（1 台を複数人で使うなら、使う人がログインし直す） |

| モック | **`docs/mockups/signature-checkin-mock.html` の内容で確定**（スマホ縦横・タブレット縦横のレスポンシブ） |
| 文言 | サイン欄のボタンは「**消してもう一度**」（「書き直す」は使わない） |
| 順番 | **PC から時刻を合わせる機能を出した後に実装**する |
| バックアップ | **サインの画像のフォルダを日ごとのバックアップに含める**（証拠なので失わない） |

上の決定で §3・§4 の案のうち次が変わる: 利用者マスターの「記録の方法」は作らない（Q3）／署名した人の区分は作らない（Q4）／取り出しの権限は担当外・期間外も可（Q6）。

## 6. 規模の見込み
- バックエンド: マイグレーション 1 本（CHECK・新しい表・利用者マスターの列）・サインの受け取りと取り出しの API・打刻の判定に `'signature'`・打刻履歴と帳票の表示。
- スマホ: サイン欄の画面・訪問の詳細の出し分け・圏外のときの画像の保存と再送（IndexedDB）。
- PC: 利用者マスターの設定・打刻履歴の詳細でサインの画像・モニターの印。
- 進め方: このたたき台で Q1〜Q8 を決める → スマホのモック → 実装とレビュー → デプロイ → 実機で確認。
