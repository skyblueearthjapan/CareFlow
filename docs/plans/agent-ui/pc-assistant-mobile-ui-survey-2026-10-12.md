### I-4. らく助らしさ（マスコット・言葉・大きさ）
- **状態 × ポーズ**（Mini の 6 表情の写し。`docs\mockups\mascot-candidates\rakusuke-pose-*.png`）：待機＝bow（おじぎ）、受け取り・考え中＝search（探す）、作業中＝laptop、案ができた＝propose（差し出す）、反映した＝stamp（はんこ）、確認待ち＝waiting。ポーズは**最下行（ライブ行）と空画面**にだけ出し、毎行には出さない（会話が重くなる）。`prefers-reduced-motion` では動かさない。
- 誰の行のアイコンは**マスコットの顔**（PC Assistant の頭文字の丸の代わり）、作業中は外周がピンクで“呼吸”。
- 色：主色＝#e15a7f（送る・新しい相談・反映する）、意味の色は PC Assistant と同じ（青＝作業中、琥珀＝あなた待ち、赤＝失敗、緑＝反映済み）。**ピンクを“待ち”に使わない**（琥珀と混ざる）。
- 文字：本文 15〜16px、カードの見出し 17px、ボタン 15px 太字、押せる物は 44px 以上（主要ボタンは 48px）。Mini ほど大きくはしない（表が多いので）。
- 言葉：「承認」→「この案で反映する」、「会話」→「相談」、「新しい会話」→「新しい相談」、「作業」→「調べました／作りました」、「出力」→出さない、「AI のモデル」→表に出さない（設定の奥）。
- 🎤：入力欄の右下に 56px の丸（ピンクの輪）。聞いている間は波形と「聞いています」、言い方の例を 3 秒ごとに替える（Mini）。2 分まで。

### I-5. 片手操作の工夫
- ☰ は左上（PC Assistant・Claude アプリと同じで覚えやすい）だが、**画面の左端からの右なぞりでも開く**ようにする（PC Assistant には無い）。
- 「決めてほしいもの」は**見出し下の琥珀 1 行**から 1 押しで行ける（PC Assistant の attn 行）。
- 主ボタン（送る・反映する・新しい相談）は**下半分**に置く。ドロワーの［＋ 新しい相談］は上だが、会話画面が空の時は**入力欄のすぐ上**にも「新しい相談を始める」を出す。

### I-6. 作るときの注意（PC Assistant の失敗から）
1. **差分で描く**（React の key を安定させ、メッセージ行を作り直さない）。作り直すと長押しの選択・スクロール・IME が壊れる（REPORT_PH8・PH9）。
2. 時計は**ページで数える**（サーバーは開始時刻だけ送る）。ライブ行は 1 行固定の高さ。
3. 下への追従は「下から 24px 以内なら追う」。PC Assistant に無い**「↓ 新しいメッセージ」ボタン**は足してよい（上を読んでいる時に案が届いたら）。
4. SSE が切れたら 3→30 秒で張り直し、45 秒無音で張り直し、画面に戻ったら即座に読み直す。「つながっていません。最後に受け取った内容です」の帯。
5. 開いているシートの iframe を作り直さない。シートを閉じたら開いたカードへフォーカスを戻す。
6. iOS：入力は 16px、`viewport-fit=cover`＋safe-area、Web Push はホーム画面に追加した時だけ・許可はタップの中で。キーボード表示時の入力欄の位置は**実機で確認**（PC Assistant も特別な処理なし）。

### I-7. 決めること（PO に聞く）
1. /m に出すこと（構想 §2-2b「/m には出さない」からの変更）と、下タブを会話中に隠すこと。
2. 裏で同時に動かせる相談の数（1 か 2 か）。
3. 相談の保存期間（案：90 日）と、消せる人（本人のみ／admin 全員）。
4. 通知の本文に名前を出さないこと。
5. 音声入力の方式（ブラウザー標準か VPS 側か）。
