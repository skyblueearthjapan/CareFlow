# らく助エージェント — 画面ごとに「できること」の洗い出し（2026-10-12・調査）

右下の小窓のらく助エージェントが、**いま開いている画面**（週・患者・職員などの手がかり）を受け取ったときに、その画面で何を手伝えるかを、画面ごとに並べました。入力の代行だけでなく、**画面の説明・質問への答え・分析・注意・チェックリスト・お知らせ文の下書き**も含めます。

- 調べた範囲: 画面 `frontend/app/**/page.tsx`（46 画面）と主な部品、エージェントの道具（`agent/rk/ops/*.py` の書き込み 25 種・`agent/sql/*.sql` 31 本・読むだけの POST の許可リスト `agent/rk/readonly_posts.py`・スキル 9 本 `agent/.agents/skills/`・約束 `agent/AGENTS.md`）、バックエンドの API（`backend/app/api/v1/*.py`）。
- コードは変えていません（この文書を書いただけ）。

**まず手を付けるとよいこと（土台）**

1. **画面の文脈を実際に送る**: 約束（`agent/AGENTS.md` §11）には「発話の頭に `{screen, week, patient_id, staff_id, …}` が付く」とありますが、画面側（`frontend/components/agent/AgentWidget.tsx`・`relay.ts`）にはまだ送る処理が見当たりません。ここが付けば、上の 10 件はほぼ「言葉を言うだけ」で動きます。手間: 小〜中。
2. **画面の説明書（エージェント用）を 1 本**: 各画面のボタン・色・印の意味を短く書いたもの（例 `agent/screens.md`）。おすすめ 9 の元になり、全画面で効きます。手間: 中（文章を書く仕事）。
3. **足りない読み取り/書き込みは小さく足す**: 下の表の「△」を、価値の高いものから 1 つずつ（§3 にまとめ）。

## 1. 表の見方

- **種類**: 【説明】＝画面や数字の意味を説明・質問に答える／【分析】＝調べる・比べる・注意やチェックリストを出す／【代行】＝入力・編集を代わりに行う（案→了承→バックアップ→反映→照合の順。`AGENTS.md` §4）。
- **使うもの**: ○＝いまの道具でできる（読み取り API・読む SQL・書き込みの手順・スキル）／△＝足りない（新しい読む SQL・書き込みの手順・バックエンドの API が要る）／×＝人だけ（エージェントにさせない）。
- **価値**: 高・中・低（お客様の時間がどれだけ減るか・事故がどれだけ防げるか）。
- **危うさ**: 低＝読むだけ／中＝書くが元に戻せる／高＝元に戻しにくい・実績や本人の意思に関わる。
- **手間**: 小＝スキルの文章を足すだけ／中＝読む SQL や手順を 1 本足す／大＝バックエンドの API から作る。

## 4. 個人情報の扱い（名前が ChatGPT・Claude に渡ること）

- **どこまで渡るか**: 画面の文脈は ID だけ（名前は入らない）ですが、エージェントは答えるために `rk` で名前・住所・予定を読むので、**利用者と職員の名前・予定・住所の一部は AI の会社（Anthropic・OpenAI）に送られます**。契約の形（API のデータ保持の条件・ChatGPT の学習に使わない設定）を、お客様に説明して了承を得る必要があります（PO 判断）。
- **特に気をつけるもの**: 音声記録の要約・文字起こし（健康の情報）→ 聞かれた方・聞かれた範囲だけ。NG の理由メモ → 内部用（答えに出さない）。住所 → 必要なときだけ。
- **読まないもの**: カイポケのログイン情報・パスワード・監査ログの本文（`AGENTS.md` §5 の「見てはいけない列」）。
- **残す場所**: 名前入りの A4・Excel は `docs/reports/agent/` だけ（git に入れない・外に出さない）。
- **今後の選択肢**: 名前を「A 様・職員 1」のように置き換えて AI に渡し、画面に出すときに戻す方法（仮名化）もあります。精度と手間の釣り合いを見て検討（手間: 大）。

## 5. 人だけに残すもの（エージェントにさせない）

| もの | 理由 |
|---|---|
| 職員本人の打刻・退出・サイン・不在の記録・録音・休み申請・パスワード | 実績や本人の意思の偽装になる |
| 実績の時刻を合わせる（当面） | 請求の根拠になる記録。エージェントは「候補と理由」を出すまで |
| 申請の承認・却下の最後のひと押し（当面） | 本人への返事になる。エージェントは材料と文の下書きまで |
| 患者・ユーザーの削除、QR・パスワードの再発行 | 取り返しがつかない |
| カイポケの月初展開・置換の取り込み・取り込み前に戻す・ログイン情報 | 事故の前例（8/31）・秘密情報 |
| 自動割当・全面最適化・範囲最適化の適用・一斉の担当はずし・週のコピーの上書き | ならし案を崩す・戻せない |
| Excel の完全置換・固定枠の一括置換・職員の全項目保存 | 消える・退職者が戻る事故 |
| 設定（最適化ルール・打刻のしきい値・機能の切り替え・ユーザー） | 全社に効く。説明と試算まではエージェント |
| 外へのお知らせ（利用者・家族・カイポケ以外） | 送る機能が無い。文の下書きまで |
