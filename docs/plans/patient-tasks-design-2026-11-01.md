# 事務所からのやること（看護師へのタスク）設計（2026-11-01）

状態：**案**（PO と方向を決めた。実装の了承はまだ）。モック：`docs/mockups/patient-tasks-mock.html`（スマホで見られる写しを claude.ai の非公開ページにも置いた）。

## 1. 目的

事務所（松岡さん）から看護師への指示を、らく助の上で出す。患者様ごとに要る資料・取りたい情報・時期が違うので、忘れないように、その方を訪問するときに看護師のスマホに出し、済んだら完了にする。完了していないものは事務所で分かる。

発端：松岡さん（11/1）「事務から看護師への指示を、らく助上でできないか」。項目の例：配布物あり（会社からの案内）・実費集金・GAF 入力・計画書サイン・アルバム格納（自立支援／子供医療／心身障害者／一人親）・保険証チェック（マイナンバー・アルバム格納）・上限負担額確認・自立支援受給者証の期限切れを伝える・伝言（自由な文）。

## 2. PO の決定（11/1）

1. **結び付け＝患者様＋日付**。訪問 1 件には固定しない。
2. **日付＝この日から出す**。その日以降の、その患者様の最初の訪問に出す。登録の時点で訪問が無くても、後から予定ができればその訪問に出る。取消・日付の変更なら次の訪問に出直す。担当が代わっても、その日に行く人に出る。
3. **持ち越し**：完了しないまま日付が過ぎたら「持ち越し」の印を付けて、次の訪問にも出し続ける。
4. **完了を押せる人**：その訪問の担当（2 名訪問は両方・同行を含む）がスマホで。事務所（管理者）は PC で完了・完了を戻す・取り消すができる。誰がいつ押したかを残す。
5. **最初の範囲**：付ける・スマホで見る・完了・一覧・ベルの通知。毎月の繰り返しの自動作成と、受給者証の期限からの自動作成は次の段。
6. **PC の形**：付けるのは**訪問モニターの詳細**（今の画面に「事務所からのやること」の枠を足す・カードに残りの件数の印）と、**左のメニューに足す新しいページ「やること」**（未完了・期日を過ぎた・完了で絞る一覧、「＋ やることを付ける」で患者様・日付・項目・伝言を選んで登録、どの訪問に出るかをその場で表示、項目の設定）。

## 3. 画面

- **スマホ（看護師）**：今日の一覧の上に「今日のやること N 件」の帯。訪問カードに「やること N 件（持ち越しあり）」。訪問詳細に「事務所からのお願い」（四角を押して完了・もう一度で戻す）と「事務所からの伝言」（「読みました」）。
- **PC 訪問モニター**：カードの右上に 📋N（期日を過ぎたものがあれば赤、全部済みなら ✓）。詳細の欄に一覧と「＋ やることを付ける」。
- **PC やること（新しいページ）**：未完了・期日を過ぎた・完了の件数、絞り込み（状態・看護師）、表（日付・患者様・やること・伝言・出す訪問・状態）、完了／戻す、項目の設定。
- **ベル**：付けたとき、その時点で出す訪問の担当に通知する（アプリ内の通知。プッシュは無い）。

## 4. 作り（案）

- 表 `patient_tasks`：患者・日付（この日から）・項目（`task_item_types` への参照・空なら伝言）・伝言・作った人と時刻・完了した人と時刻と訪問・取消の人と時刻。alembic は 0103。
- 表 `task_item_types`：項目の一覧。**事業所の情報をコードに書かない**ため、項目は設定の画面で事務所が足す・消す（並び順・使う／使わない）。最初の項目は本番に出した後、画面かエージェントで入れる。
- 出す訪問は保存せず、見るたびに決める（患者・日付以降・取消でない最初の訪問）。完了したときだけ、その訪問を記録する。
- API：やることの作成・一覧・完了・戻す・取消（管理者）、項目の設定（管理者）、職員は自分の訪問の分だけ読める・完了できる（`visits.py` の職員の絞り込みと同じ考え）。
- 通知：`notifications` の新しい種類（例 `task_assigned`）。
- エージェント：次の段で `agent/rk/ops/tasks.py`。
