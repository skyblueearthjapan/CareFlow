# らく助アドバイザーUX 設計書（R-10・2026-07-10 起草）

目的: スケジュール画面の提案・診断系7機能を「らく助が語りかける」体験に統一し、
システムの指摘を威圧感なく受け取れるようにする（PO構想: アドバイザー=ソフトの要）。

## 1. 共通部品「RakusukeSays」（らく助の吹き出し）

```
[らく助ポーズ画像] ＜吹き出しカード＞
                    らく助の一言（太字・話し言葉）
                    （以下、既存の提案/診断コンテンツをそのまま格納）
```

- `components/brand/Rakusuke.tsx` に `RakusukeSays` を追加:
  `pose` / `message`（らく助の一言）/ `children`（既存UI本体）/ `tone`（normal | warn）。
- 見た目: 左にらく助(h-14〜16)、右に角丸吹き出し（淡ピンク地 `--brand-primary-50`・
  左に三角しっぽ）。tone=warn は地色を淡アンバーに（機能色の意味体系は不変）。
- 配置原則（R-4と同じ）: ダイアログ/パネルの**ヘッダ部に1つだけ**。表・グリッド・
  候補リストの中身には出さない。既存の文言・データ表示は変更せず「冒頭の一言」を足す。

## 2. 適用マップ（7機能 × ポーズ × 一言の例)

| 機能 | 場所 | ポーズ | らく助の一言（例） |
|---|---|---|---|
| スケジュール診断 | 診断結果パネル冒頭 | think→結果で分岐: 問題0=cheer / 有=puzzled | 「診断しました！気になる点が◯件あります」/「今週はいい感じです✨」 |
| スケジュール最適化 | 最適化提案ダイアログ冒頭 | idea | 「もっと楽になる並びを見つけました！」 |
| プール一括投入提案 | BulkPoolInsertDialog ヘッダ | idea | 「保留中の◯名さん、入れそうな枠がありますよ」 |
| 単体プール投入提案 | 患者詳細の提案セクション | idea (sm) | 「この方、ここに入れそうです」 |
| ずらせば入る | 提案カード群のヘッダ | calendar | 「少しずらすと入ります。どうしますか？」 |
| 定員超過の候補 | 相談ダイアログ冒頭 | heart + tone=warn | 「定員を超えそうです。一緒に調整しましょう」 |
| 配置改善提案 | ImprovementSuggestionsSection ヘッダ | idea | 「配置をこう変えると移動が楽になります」 |

文言トーン規約: 断定しない（〜できそうです/〜はいかがですか）・件数を先に言う・
絵文字は✨程度まで・警告でも責めない（「一緒に調整しましょう」）。

## 3. 画像素材の方針

- **まず既存10ポーズで全面実装可能**（idea/think/puzzled/cheer/heart/calendar で7機能を賄える）。
- 追加が望ましい素材（後日差し替え）: ①虫眼鏡で診断ポーズ ②大きくひらめくポーズ。
  **DALL-E等での新規生成は画風不一致のリスクが高い**ため、正典シートと同じ生成元
  （POの画像生成環境）で追加発注→ extract_rakusuke.py 方式で切り出しを推奨。
  暫定でDALL-E生成を使う場合も「差し替え前提のプレースホルダ」と明記する。

## 4. 実装計画（R-10）

1. `RakusukeSays` 実装＋Storybook代わりに docs/mockups へ1枚モック（任意）
2. 適用は上表の7箇所（対象ファイル: components/schedule/v2/ 配下の各ダイアログ/セクション、
