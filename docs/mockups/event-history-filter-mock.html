期間タブ

  • 今後（既定）= 今日以降を近い順。今日の行は薄桃色で強調
  • 今週 = 月〜日 / 過去 = 昨日以前を新しい順（遡り）
  • すべて = 全期間を古い順（現状と同じ並び）

検索とチップ

  • 検索はタイトル+備考の部分一致。「患者さん別」「会議別」はここで拾う（例:「鈴木」「面談」で試せます）
  • 定例を隠す = 朝会・休みなどの毎回同じものを除外（実データの66%が朝会のため）
  • 出所チップ（カイポケ取込/手動）は排他、研修のみは種別絞り込み
