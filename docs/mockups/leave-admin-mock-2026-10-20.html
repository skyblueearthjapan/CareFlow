休み・月確定

職員のスマホ：休みの申請

今は「休みを申請」（日を選んで送るだけ・終日のみ）と「出勤カレンダー」（見るだけ）が別のページです。これを 1 つの「休み」ページにまとめ、自分の月のカレンダーを見ながら、その上で申請する形にする案です。

入れ方

上で種類（公休・午前休・午後休・有給）を選んでから日を押します。管理者の表の「押すと入るもの」と同じ考え方です。種類を変えてもう一度押すと種類が変わり、同じ種類で押すと外れます。選び終えたら下の「N 日を申請する」で、メモを付けて送ります。

カレンダーに出すもの

  • 出勤の日（白）・勤務外の曜日（灰色）
  • 承認された休み（塗り）・申請中（枠）・却下（✕・理由は下の一覧）
  • 今選んでいる日（濃い色・種類つき）

決まったこと（PO 2026-10-20）

  • 「休みを申請」と「出勤カレンダー」を 1 つの「休み」ページにまとめる
  • 休みは数だけ見せる（必要休日数・あと何日は出さない）
  • その日ほかに何人休むかは見せない
  • 締め切りは前の月の 20 日。過ぎたら日を押すと「変更をお願いする」（理由つき）

見本の職員：佐々木 恵さん（月〜土の勤務）。12 月は土日 8 日＋祝日 0 日で、必要休日数は 8 日です。

      4. 12 月中
        急な休み・変更

        照合で差分 0 件のあと、管理者が「実績を記録する」

        カイポケと比べて休みの差分が 0 件になってから押す（自動ではない）。照合を済ませた休みで実績の行を入れた確定版を作り、以後は書き換えない。保存年数のあいだ残す。
