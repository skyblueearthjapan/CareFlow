流れ

  • 「提案を見る」（または帯の「提案を見る」）→ 担当なしの各コースに ◎ N名 引受可 バッジ
  • バッジ／帯クリック → コース提案: ◎（丸ごと可）は割当ボタン、△ は理由のみ、× は折りたたみ
  • ◎ が 0 名なら「1件ずつ分けて入れる」へ誘導 → 訪問クリックで患者1人の提案

保留プールとの対応

  • プール「効果を表示」＝「提案を見る」（on-demand・自動では回さない）
  • プールは「空き時刻」を探す／ここは「時刻固定で人」を探す（急休の逆操作）
  • 提案の判定は急休と同じ単一ソース（休み・NG・性別・新人・拠点・イベント・時間重なり（同住所免除）・同行・馴染み）

実行

  • コース丸ごと＝訪問ごとに付替（同一操作・戻る1回）。NG/性別は確認→続行
  • 割当後は提案を再計算（他コースの候補が変わるため）
  • すべて今週だけ・型は不変
