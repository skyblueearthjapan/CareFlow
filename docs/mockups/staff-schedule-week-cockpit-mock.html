型 → 今週 → カイポケ の流れ

  • 📐 型から今週を作る(=週生成)で固定コース・固定イベント(朝会)を展開。手で動かした「今週」分と青ピンは保護
  • 🤖 自動で割り当てる(=Layer3)で未割当コースを一括貼り。手貼り済みは動かさない
  • そこから先は盤面で自由に編集 → 変えたものに ●未送信 が付く → バーから1件/全件 ⇧送信
  • 各予定の出所は上のチップで集計: 型どおり / 今週だけ / カイポケ由来 / 🔒固定

急な休み・キャンセル・変更・新規

  • セルにマウスを乗せると 休みにする / ＋訪問 / ＋イベント。休みにすると、その日のコースの代替候補(◎空き/△重なり/×NG)を1パネルで選んで付替 → ●未送信
  • 訪問クリック → 今週だけ取消 / 担当変更 / 時刻変更 / 型も変える…。取消は打消線で残り(送信で削除)
  • マスタに触るのは「型も変える…」を選んだときだけ(憲法1)

同期の3態と固定イベント

  • ✓同期済(表示なし) / ●未送信(らく助が進んでいる・RPA不要で即分かる) / ⚠カイポケ側が違う(🔄突合で判明・⇩取込 か ⇧上書き を差分ごとに選ぶ)
  • 全件ボタン: 未送信⇧全件 / 差分⇩全件(カイポケが正) / 差分⇧全件(らく助が正)。いずれも2段クリックで実行。当日以前は自動で除外
  • 朝会などの固定イベントは盤面最上段の 「全員（固定）」帯に1行でまとめ🔒。休みの人は自動除外。個別に外すときは「今週だけ」か「型も」
  • タイムラインではバーを横にドラッグ=時刻変更(15分刻み)、別の行へ=担当変更。どちらも●未送信になる
