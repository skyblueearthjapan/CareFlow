ドラッグ移動 — 本番と同じ二択

カードを離すと「この週だけ移動」か「固定パターンごと変更」かを選びます（既存 fix-or-pattern API と同じ契約）。ピン留め🔒は掴めず、重なり・会議帯・勤務外へは置けません。すべての変更は「元に戻す」できます（op-log 準拠）。

プール投入 — 手でも、提案でも

右パネルの患者をタイムラインへ直接ドラッグ（place-and-fix 相当）、または「最適配置の提案」で候補3件から選択（propose-slots 相当）。候補にマウスを乗せると配置先の枠がタイムライン上で光り、採用すると同じ二択（固定枠として/この週だけ）で確定します。

患者ごとの改善提案 — 詳細ポップから

カードをクリック → 「この患者の改善提案」で、移動時間が縮む再配置案を提示。提案にマウスを乗せると移動先が光り、現在地に取り消し斜線が出ます。採用は1クリック（apply-individual 相当・undo可）。
