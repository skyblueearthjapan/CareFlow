導線 A・B（予定あり）

  • 訪問詳細の訪問中パネルに「録音を始める」ボタンを追加（CheckInButton と同意匠・48px）
  • 到着打刻の前後にかかわらず録音可。QR 代行・予定外（導線 B）も同じ詳細画面を使う
  • 患者名を画面に固定表示して誤録音を防ぐ

導線 C（QR なし・先に録音）

  • 現場で患者を探す操作が録音開始を遅らせないよう「先に録音・後で患者選択」を許容
  • 24 時間紐付けなしは admin 画面に「要紐付け」として出す
  • 誤紐付けは admin が変更可（監査ログ）。本人は紐付け後 24 時間以内に変更可

iOS Wake Lock（重要）

  • iOS Safari PWA は画面ロック・バックグラウンドで MediaRecorder が停止する
  • Wake Lock API で消灯を防ぎ「録音中は画面を点けたまま」警告帯を常時表示
  • 着信で止まる可能性あり。「ボイスメモから取り込む」リンクを保険として配置

要約の構成

  • 主訴・様子 / バイタル / 処置・ケア / 申し送り / 次回 の 5 セクション
  • Vertex AI Gemini 2.5 Flash 1 コール（文字起こし＋要約）推奨。月400件≈$32
  • 要約はスタッフが「確認済み」にする（誤りの責任とトレーサビリティ）

音声・データの保持

  • 音声: 既定 90 日で削除（設定可・下限 30 日）。cron で purge-gps 型パージ
  • 文字起こし・要約: 訪問データと同じ寿命
  • アップロード失敗時は IndexedDB に残し電波復帰で自動再送（打刻キューと同 UX）

デザイン規約準拠

  • 本文 14px・バイタルチップ 13px・メタ情報 12px（11px 以下は使用禁止）
  • モーダルは 1024px・2列・max-h 90vh（add-visit-anywhere §3-5 基準）
  • マスコットは「状態の瞬間」だけ（文字起こし中・空状態）・一覧に常駐させない
  • アイコンは lucide 風インライン SVG。絵文字は 🎙 のみ
