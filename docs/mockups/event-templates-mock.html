よく使うイベントを「ひな形」として登録しておくと、イベント追加ダイアログのプルダウン（モック③）に出る。手入力のほか、過去の履歴から回数付きでワンクリック登録できる。

📍 置き場所A: スタッフ一覧ページの上部（事業所共通のひな形）

イベントひな形（共通）

ここに登録したひな形は、スケジュール画面・スタッフマスタの「イベント追加」のプルダウンに全スタッフ共通で表示されます。⠿ で並べ替え＝プルダウンの表示順。

⠿イベントカンファレンス13:00〜14:00
⠿イベントサービス担当者会議時間はその場で入力🔒
⠿研修社内研修（Zoom）14:00〜15:30
⠿イベント意見交換会時間はその場で入力無効（プルダウンに出ない）

過去のイベント履歴から追加

直近6ヶ月の履歴をタイトルで集約（朝会・休みなどの定例は除外）。＋を押すとひな形に登録されます。

髙梨さんのひな形（個人）

このスタッフを選んだときだけプルダウンに出るひな形。共通に置くほどではない個人の定型（特定の面談・定期の役割など）に。

⠿イベント面談 松岡14:00〜15:00
⠿イベント計画書、報告書作成時間はその場で入力

ひな形が持つ情報

  • タイトル / 種別（イベント・研修）/ 時刻（省略可=その場で入力）
  • 🔒（絶対に潰せない）/ 備考 / 表示順 / 有効・無効
  • 共通（全員のプルダウンに出る）と個人（そのスタッフのときだけ）の2階層

履歴から追加（資産の活用）

  • 過去イベントをタイトルで集約し回数付きで提示 → ＋でひな形化
  • 朝会・休みなど毎回同じものは対象外（固定イベント側の役割・モック④）
  • このほかイベント追加ダイアログの「☆この内容をひな形に保存」でも登録可（モック③）

削除・無効化の挙動

  • 👁 無効化 = プルダウンから消えるだけ。登録済みイベントには影響しない
  • ひな形はあくまで「入力の型」。過去のイベント行とは独立
