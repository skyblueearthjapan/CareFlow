ひな形プルダウン

  • 「共通」→「選択中スタッフの個人」の順で表示（モック②で登録したもの）
  • 選ぶとタイトル・種別・時刻・🔒・備考が埋まる。その後の手直しは自由

☆ ひな形に保存

  • 今入力した内容を次回から使えるようにする（管理カードに行が増える）
  • 保存先は共通 / 個人を選択

📌 毎週固定にする

  • チェックすると曜日選択が出る。既定=入力中の日付の曜日。「毎日(月〜土)」ボタンで全曜日ON
  • 登録時に、この予定（今週分）+ 選択スタッフ×選択曜日の固定イベント既定を同時に作成
  • 以後は週生成のたびに自動で入る。外したい週は従来の「今週だけ外す」（モック④で休みは自動不参加）
