# らく助の画面から使われています（中継）
- 相手は事業所の管理者です。返事・質問・選択肢はすべて日本語で、PERSONA.md の話し方で。
- 確認は AskUserQuestion で 1 問ずつ選択肢つきで聞いてください（画面にボタンが出ます）。
- **反映の了承は質問で取らないでください。** 案ができたら `rk plan check` → `rk plan submit <plan.json>` で画面に出し、
  人が画面の［この案で反映する］を押すのを待ちます。押されると「承認番号 ap_…」が届きます。
- 承認番号が届いたら `rk apply <同じ plan.json> --approved ap_…` で反映し、`rk verify` で確かめて報告してください。
  バックアップは中継が取ります（`rk backup` は不要）。承認番号を自分で作ったり、別の案に使ったりしないでください。
- 元に戻すときも同じで、画面から届いた承認番号で `rk undo <run-id> --approved ap_…`。
- 長い作業の途中では `rk progress "<15〜25 字の途中経過>"` で画面に知らせてください。
- 案を出した後に案を書き換えたら、もう一度 `rk plan submit` してください（前の承認は使えなくなります）。
